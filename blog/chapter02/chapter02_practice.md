# 1. 이번 과제의 학습 목표

과제를 끝내면 다음을 할 수 있어야 합니다.

- 큰 요구사항을 컴퓨터가 실행할 수 있는 **작은 행동 단위**로 나눌 수 있다.
- 작은 단계의 **올바른 실행 순서**를 정할 수 있다.
- 뒤 단계가 앞 단계의 결과를 사용하는 **의존 관계**를 설명할 수 있다.
- 한국어 절차를 **의사코드(Pseudocode)**로 바꿀 수 있다.
- 의사코드를 Python 코드로 한 단계씩 번역할 수 있다.
- 코드를 실행하기 전에 변수의 변화를 손으로 따라가는 **실행 추적(Tracing)**을 할 수 있다.
- 요구사항이 바뀌면 코드부터 고치는 것이 아니라 **절차에서 어떤 단계가 추가·변경되는지** 먼저 찾을 수 있다.
- Dictionary에서 `name`, `score`, `attendance`처럼 여러 Key-Value를 다룰 수 있다.
- `and`, `or`, `if / elif / else`가 포함된 판단 흐름을 순서대로 설명할 수 있다.
- f-string을 이용하여 여러 값을 읽기 좋은 문장으로 출력할 수 있다.
- 모든 실습 과정을 한 개의 Notebook에 정리하고 본인 GitHub 저장소 URL로 제출할 수 있다.

이번 과제에서도 **AI 사용은 허용**합니다.

하지만 AI에게 **정답, 코드, 문제 해결 순서, 오류 수정 코드**를 요청하면 안 됩니다.

## AI에게 질문해도 되는 것

```text
"프로그래밍에서 의사코드가 무엇인지 코드 없이 설명해 줘."
"and와 or라는 용어의 일반적인 차이를 예제 코드 없이 설명해 줘."

"GitHub에 ipynb 파일을 올리는 방법을 알려 줘."
```

## AI에게 질문하면 안 되는 것

```text
"이 문제를 단계별로 나눠 줘."
"이 문제의 의사코드를 작성해 줘."
```

문제 전체를 AI에게 붙여 넣고 해결 방향을 묻는 것도 금지합니다.

- 학생 한 명은 `name`, `score`, `attendance`를 가진다.

그 다음 Code 셀에서 직접 작성합니다.

작성과 실행을 모두 끝낸 뒤에만 아래 기준 코드와 비교합니다.

```python
students = [
    {"name": "민수", "score": 95, "attendance": 90},
    {"name": "지영", "score": 85, "attendance": 95},
    {"name": "현우", "score": 72, "attendance": 65},
    {"name": "수진", "score": 78, "attendance": 88}
]

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    if score < 60 or attendance < 70:
        grade = "F"
    elif score >= 90 and attendance >= 80:
        grade = "A"
    elif score >= 80 and attendance >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    else:
        grade = "D"

    print(
        f"{name}: 점수 {score}점, "
        f"출석률 {attendance}%, 등급 {grade}"
    )
```

# 22. Chapter 03 준비 코드 — 반드시 직접 입력하고 암기

아래 코드는 복사해서 붙여 넣지 않습니다.

먼저 전체 처리 순서를 Markdown 셀에 직접 작성한 뒤, 눈으로 보고 한 줄씩 직접 입력합니다.

## 요구사항

- 학생 한 명은 `name`, `score`, `attendance`를 가진다.
- 학생을 한 명씩 확인한다.
- 원래 점수에 5점을 더해 `adjusted_score`를 만든다.
- 보정 점수 또는 출석률을 기준으로 등급을 결정한다.
- 결과는 f-string으로 출력한다.

```python
students = [
    {"name": "민수", "score": 95, "attendance": 90},
    {"name": "지영", "score": 85, "attendance": 95},
    {"name": "현우", "score": 72, "attendance": 65},
    {"name": "수진", "score": 78, "attendance": 88}
]

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    adjusted_score = score + 5

    if adjusted_score < 60 or attendance < 70:
        grade = "F"
    elif adjusted_score >= 90 and attendance >= 80:
        grade = "A"
    elif adjusted_score >= 80 and attendance >= 80:
        grade = "B"
    elif adjusted_score >= 70:
        grade = "C"
    else:
        grade = "D"

    print(
        f"{name}: 원점수 {score}점, 보정점수 {adjusted_score}점, "
        f"출석률 {attendance}%, 등급 {grade}"
    )
```

> **코드는 생각의 출발점이 아니라, 올바른 순서로 정리된 절차의 마지막 표현이다.**
