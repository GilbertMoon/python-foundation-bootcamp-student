## 11. STEP 9 — 이제 Python으로 구현합니다

먼저 배송 결과 기능입니다.

```python
def get_delivery_result(amount):
    if amount >= 50000:
        return "무료배송"
    else:
        return "배송비 발생"
```

이제 전체 흐름을 작성합니다.

```python
orders = [
    {"order_id": 1001, "customer": "민수", "amount": 48000, "paid": True},
    {"order_id": 1002, "customer": "지영", "amount": 72000, "paid": True},
    {"order_id": 1003, "customer": "현우", "amount": 35000, "paid": False},
    {"order_id": 1004, "customer": "서연", "amount": 91000, "paid": True},
    {"order_id": 1005, "customer": "준호", "amount": 51000, "paid": True}
]

paid_count = 0
total_amount = 0
highest_amount = None

for order in orders:
    if not order["paid"]:
        continue

    customer = order["customer"]
    amount = order["amount"]

    paid_count += 1
    total_amount += amount

    if highest_amount is None or amount > highest_amount:
        highest_amount = amount

    delivery = get_delivery_result(amount)

    print(customer, amount, delivery)

if paid_count > 0:
    average_amount = total_amount / paid_count
else:
    average_amount = 0

print("결제 완료 주문 수:", paid_count)
print("총 주문 금액:", total_amount)
print("평균 주문 금액:", average_amount)
print("최고 주문 금액:", highest_amount)
```

```text
continue의 동작
Dictionary 접근 방식
함수 return 동작
```

등을 확인할 수 있습니다.

### 3단계 — 구현 완료 후 AI로 검증

자신의 코드와 사고 과정을 먼저 완성한 뒤 AI에게 검토를 요청합니다.

![올바른 AI 활용 순서](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter12/ai-use-order.jpg)

권장 순서:

```text
내가 먼저 생각
→ 직접 작성
→ 실행
→ 공식 문서 확인
→ 직접 수정
→ AI 검증
```

AI에게 다음처럼 요청할 수 있습니다.

```text
내가 아래 문제를 이런 순서로 분해했고 직접 구현했습니다.
정답 코드를 새로 작성하지 말고,
내 문제 분해 방식에 빠진 조건이 있는지와
내 코드의 논리 오류 가능성만 검토해 주세요.
```

이렇게 사용하면 AI가 **생각을 대신하는 도구**가 아니라 **생각을 검증하는 도구**가 됩니다.

> **AI 없이 개발하는 법을 배우는 것이 아니라, AI에게 생각을 맡기지 않는 법을 배웁니다.**

## 21. 지금 배운 사고는 Python에서 끝나지 않습니다

우리가 지금까지 한 일을 다시 보면 데이터베이스와 데이터 분석에서 그대로 사용되는 사고가 많습니다.

![Python에서 Database SQL pandas Data Analysis로 이어지는 다리](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter12/python-to-data-analysis-bridge.jpg)

예를 들어:

### Python의 필터링

```text
for + if
→ 필요한 데이터만 선택
```

이 사고는 SQL에서:

```sql
WHERE
```

로 이어집니다.

pandas에서는 조건 필터링으로 이어집니다.

### Python의 집계

```text
합계
개수
평균
최댓값
```

이 사고는 SQL에서:

```sql
SUM
COUNT
AVG
MAX
```

로 이어집니다.

pandas에서도 같은 종류의 집계 연산을 사용합니다.

### List of Dictionaries

```text
Dictionary 한 개
→ 하나의 record / row처럼 생각

Dictionary 여러 개의 List
→ 여러 row를 가진 table처럼 생각
```

이 구조를 이해하면 데이터베이스의 행과 열, pandas의 DataFrame을 훨씬 자연스럽게 받아들일 수 있습니다.

### 함수 파이프라인

```text
입력
→ 처리
→ return
→ 다음 처리
```

이 사고는 이후 데이터 처리 파이프라인에서도 그대로 이어집니다.

즉 이번 과정에서 연습한 것은 Python에만 필요한 기술이 아닙니다.

> **데이터를 구조화하고, 조건을 정의하고, 반복 처리하고, 결과를 검증하는 사고 자체가 다음 학습의 기반입니다.**
