## 이번 Bootcamp는 Python 문법 재수업이 아닙니다

Python 기초 수업을 이미 들었는데도 막상 문제를 보면 이런 생각이 들 수 있습니다.

- `if`가 무엇인지는 아는데 언제 써야 하는지 모르겠다.
- `for`문을 배웠는데 문제에서 반복을 어떻게 찾아야 할지 모르겠다.
- List와 Dictionary를 배웠는데 데이터를 어떻게 구성해야 할지 모르겠다.
- 예제 코드는 이해되는데 빈 화면에서 직접 작성하려면 손이 멈춘다.
- 오류가 나오면 어디부터 확인해야 할지 모르겠다.

이 과정은 바로 이 부분을 연습하기 위한 과정입니다.

앞으로의 수업에서는 `변수란 무엇인가?`, `List 문법은 무엇인가?`, `if문은 어떻게 쓰는가?`를 처음부터 다시 설명하는 데 많은 시간을 사용하지 않습니다.

대신 이미 배운 기본 문법을 이용해 다음과 같은 질문을 반복합니다.

> **이 문제에서 어떤 데이터가 필요한가?**  
> **무엇을 반복해야 하는가?**  
> **어떤 기준으로 판단해야 하는가?**  
> **결과로 무엇을 만들어야 하는가?**

즉, 문법 자체보다 **문제를 해결하기 위해 문법을 선택하고 조합하는 방법**을 연습합니다.

## 1. 먼저 완성된 코드를 봅시다

이번 Bootcamp 전체에서 반복해서 사용할 가장 기본적인 예시는 **학생 성적 데이터**입니다.

학생 세 명의 이름과 점수가 있고, 점수가 80점 이상이면 `합격`, 그렇지 않으면 `불합격`이라고 출력해 보겠습니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]

for student in students:
    name = student["name"]
    score = student["score"]

    if score >= 80:
        result = "합격"
    else:
        result = "불합격"

    print(name, score, result)
```

실행 결과는 다음과 같습니다.

```text
민수 85 합격
지영 72 불합격
현우 91 합격
```

이 코드는 길지 않지만 앞으로 사용할 중요한 Python 기본 구조가 모두 들어 있습니다.

## 3. 학생 한 명은 왜 Dictionary일까요?

먼저 학생 한 명만 생각해 봅시다.

```python
student = {
    "name": "민수",
    "score": 85
}
```

민수라는 학생에게는 두 가지 정보가 있습니다.

- 이름: 민수
- 점수: 85

Dictionary를 사용하면 각 값에 의미 있는 이름을 붙일 수 있습니다.

```python
student["name"]
student["score"]
```

이렇게 보면 첫 번째 값, 두 번째 값이라고 기억할 필요가 없습니다.

> **Dictionary는 하나의 대상을 여러 속성으로 표현할 때 유용합니다.**

---

## 4. 학생이 여러 명이면 왜 List가 필요할까요?

학생이 한 명이 아니라 세 명입니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]
```

여기서 바깥쪽 `[ ]`는 List입니다.

즉 구조를 단순하게 표현하면 다음과 같습니다.

```text
students
 ├─ 민수의 Dictionary
 ├─ 지영의 Dictionary
 └─ 현우의 Dictionary
```

학생 한 명은 Dictionary, 여러 학생은 List에 담았습니다.

이 구조는 앞으로 데이터베이스와 데이터 분석을 배울 때도 매우 자주 만나게 됩니다.

---

## 5. for문은 무엇을 하고 있을까요?

```python
for student in students:
```

이 코드를 어려운 문법으로 생각하지 마세요.

말로 바꾸면 다음과 같습니다.

> `students`에 있는 학생을 **한 명씩 꺼내서** `student`라고 부르겠다.

첫 번째 반복에서는 다음 데이터가 들어옵니다.

```python
{"name": "민수", "score": 85}
```

두 번째 반복에서는:

```python
{"name": "지영", "score": 72}
```

세 번째 반복에서는:

```python
{"name": "현우", "score": 91}
```

즉 `for`는 **여러 데이터에게 같은 작업을 반복해서 시키는 도구**입니다.

## 6. 왜 다시 변수에 저장할까요?

반복문 안에는 다음 코드가 있습니다.

```python
name = student["name"]
score = student["score"]
```

현재 처리하고 있는 학생의 이름과 점수를 각각 변수에 저장합니다.

예를 들어 민수를 처리할 때는 결과적으로 다음과 같은 상태가 됩니다.

```python
name = "민수"
score = 85
```

변수에 의미 있는 이름을 붙이면 뒤의 코드를 읽기가 훨씬 쉬워집니다.

---

## 7. if문은 '판단'을 담당합니다

이제 가장 중요한 판단을 합니다.

```python
if score >= 80:
    result = "합격"
else:
    result = "불합격"
```

사람의 말로 바꾸면 다음과 같습니다.

> 점수가 80점 이상인가?

- 그렇다면 → 합격
- 그렇지 않다면 → 불합격

여기서 특히 `>=`를 잘 봐야 합니다.

```text
>=  : 크거나 같다
>   : 크다
<=  : 작거나 같다
<   : 작다
==  : 같다
```

따라서 `score >= 80`에는 **80점도 포함**됩니다.

## 9. 이제 실행 순서를 머릿속으로 따라가 봅시다

민수부터 생각해 보겠습니다.

```text
민수 데이터 꺼내기
        ↓
name = "민수"
score = 85
        ↓
85 >= 80 ?
        ↓
True
        ↓
result = "합격"
        ↓
민수 85 합격 출력
```

다음은 지영입니다.

```text
지영 데이터 꺼내기
        ↓
name = "지영"
score = 72
        ↓
72 >= 80 ?
        ↓
False
        ↓
result = "불합격"
        ↓
지영 72 불합격 출력
```

이렇게 **실행하기 전에 결과를 예상하는 습관**을 들이는 것이 중요합니다.

## 10. 반드시 외워야 할 기본 패턴

이번 0강에서 전체 코드를 외우는 이유는 시험을 보기 위해서가 아닙니다.

앞으로 문제를 풀 때 아래 기본 패턴을 머릿속에서 바로 꺼내기 위해서입니다.

### 여러 데이터를 묶는다

```python
items = [
    {...},
    {...}
]
```

### 하나씩 처리한다

```python
for item in items:
```

### 필요한 값을 꺼낸다

```python
value = item["key"]
```

### 조건을 판단한다

```python
if 조건:
    ...
else:
    ...
```

### 결과를 출력한다

```python
print(...)
```

이 구조를 보면 앞으로 새로운 문제에서도 어떤 도구를 사용할지 훨씬 쉽게 떠올릴 수 있습니다.

## 16. 초보자가 자주 하는 실수

### 실수 1. 들여쓰기를 맞추지 않는다

Python에서 들여쓰기는 단순한 디자인이 아닙니다.

```python
if score >= 80:
    result = "합격"
```

`result` 앞의 들여쓰기는 이 코드가 `if` 조건에 포함된다는 뜻입니다.

---

### 실수 2. Dictionary key의 따옴표를 빼먹는다

```python
student["name"]
```

`"name"`은 Dictionary 안의 key 이름입니다.

다음은 다른 의미가 됩니다.

```python
student[name]
```

Python은 `name`이라는 변수를 찾으려고 합니다.

---

### 실수 3. `=`와 `==`를 혼동한다

```python
score = 85
```

`=`는 값을 저장합니다.

```python
score == 85
```

`==`는 두 값이 같은지 비교합니다.

둘은 역할이 완전히 다릅니다.

---

### 실수 4. 실행 결과를 예상하지 않고 무조건 실행한다

코드를 작성한 뒤 바로 실행 버튼부터 누르지 마세요.

먼저 스스로 물어보세요.

> **어떤 결과가 나올까?**

예상과 실제 결과가 다를 때 그 차이를 찾는 것이 프로그래밍 학습에서 매우 중요합니다.

코드 역시 이 다섯 덩어리로 기억합니다.

추천 방법은 다음과 같습니다.

1. 코드를 보면서 한 번 작성한다.
2. 실행한다.
3. 코드를 닫는다.
4. 기억나는 만큼 다시 작성한다.
5. 틀린 부분만 확인한다.
6. 다시 닫고 처음부터 작성한다.
7. 5분 안에 완성될 때까지 반복한다.

## 19. 중요한 것은 '코드를 외웠다'가 아닙니다

이번 과제의 진짜 목적은 다음입니다.

```text
코드를 외운다
      ↓
구조가 익숙해진다
      ↓
문제를 보면 비슷한 구조를 떠올린다
      ↓
새로운 문제에 구조를 적용한다
```

즉 **암기 → 이해 → 활용** 순서입니다.

외운 코드 자체가 목적이 아닙니다.

## 20. 1강에서는 무엇을 할까요?

1강에서는 학생 점수 프로그램을 다시 설명하지 않습니다.

대신 전혀 다른 문제를 하나 만나게 됩니다.

예를 들어 쇼핑몰 주문 데이터가 있을 수 있습니다.

```text
여러 고객의 주문이 있다.
      ↓
고객을 한 명씩 확인한다.
      ↓
주문 금액을 확인한다.
      ↓
50,000원 이상인지 판단한다.
      ↓
무료배송 여부를 출력한다.
```

학생 성적 문제와 전혀 달라 보이지만 구조는 사실 매우 비슷합니다.

```text
여러 학생                 여러 고객
   ↓                         ↓
한 명씩                     한 명씩
   ↓                         ↓
점수 확인                   주문금액 확인
   ↓                         ↓
80점 이상?                  50,000원 이상?
   ↓                         ↓
합격/불합격                 무료배송/배송비
```

바로 이것이 앞으로 연습할 **문제 해결 사고**입니다.
