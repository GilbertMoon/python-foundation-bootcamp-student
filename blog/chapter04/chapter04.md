# Chapter 04. 반복은 for문이 아니라 반복되는 일을 발견하는 것이다

> **이번 Chapter의 핵심은 `for` 문법을 다시 외우는 것이 아닙니다.**  
> 문제 안에서 **같은 일을 여러 대상에게 반복해야 하는 부분을 발견하는 것**이 목표입니다.

---

## `for`문을 배웠는데도 왜 반복 문제에서 막힐까요?

Python 기초 수업에서 우리는 이미 이런 코드를 배웠습니다.

```python
for student in students:
    print(student)
```

문법만 보면 어렵지 않습니다.

하지만 실제 문제를 만나면 다음과 같은 생각이 들 수 있습니다.

- 지금 정말 반복문이 필요한가?
- 무엇을 반복해야 하지?
- `student`에는 무엇이 들어오는가?
- 반복문 안에는 어디까지 넣어야 하는가?
- 반복이 언제 끝나는가?

이 질문들에 답하지 못하면 `for` 문법을 알고 있어도 문제를 풀기 어렵습니다.

그래서 이번 Chapter에서는 순서를 바꿉니다.

> **먼저 반복되는 일을 찾고, 그다음에 `for`를 선택합니다.**

---

## 1. 학생이 한 명이라면 반복문이 필요하지 않습니다

먼저 학생 한 명만 있다고 생각해 봅시다.

```python
student = {"name": "민수", "score": 85}
```

민수의 이름과 점수를 출력하려면 다음처럼 작성할 수 있습니다.

```python
name = student["name"]
score = student["score"]

print(name, score)
```

실행 결과:

```text
민수 85
```

학생이 한 명뿐이라면 이 정도면 충분합니다.

여기에는 반복이 없습니다.

---

## 2. 그런데 학생이 세 명이라면 어떻게 할까요?

이번에는 학생이 세 명입니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]
```

반복문을 사용하지 않는다면 이런 식으로 작성할 수도 있습니다.

```python
student = students[0]
print(student["name"], student["score"])

student = students[1]
print(student["name"], student["score"])

student = students[2]
print(student["name"], student["score"])
```

학생이 세 명이라면 아직 작성할 수 있습니다.

그런데 여기서 중요한 질문이 있습니다.

> **학생이 100명이라면 어떨까요?**

100번 직접 작성해야 할까요?

![수작업 100회와 반복 처리 비교](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter04/manual-vs-loop.jpg)

학생이 많아질수록 직접 한 명씩 처리하는 방식은 비효율적입니다.

그리고 더 중요한 점은, 우리가 하는 일이 학생마다 거의 똑같다는 것입니다.

```text
학생 한 명 선택
→ 이름 확인
→ 점수 확인
→ 출력
```

다음 학생도 똑같습니다.

```text
학생 한 명 선택
→ 이름 확인
→ 점수 확인
→ 출력
```

또 다음 학생도 똑같습니다.

바로 이 순간 반복을 떠올리면 됩니다.

> **여러 대상에게 같은 작업을 해야 한다면 반복을 의심한다.**

---

## 3. 반복문을 쓰기 전에 먼저 네 가지를 찾습니다

문제를 읽고 바로 `for`를 쓰지 마세요.

먼저 다음 질문에 답합니다.

### 질문 1. 데이터가 하나인가 여러 개인가?

```text
학생 한 명 → 반복 필요 없음
학생 여러 명 → 반복 가능성 있음
```

### 질문 2. 여러 데이터에게 같은 작업을 하는가?

예를 들어 모든 학생에게 다음 작업을 해야 합니다.

```text
이름 확인
점수 확인
출력
```

같은 작업입니다.

### 질문 3. 현재 처리 중인 한 개는 무엇인가?

학생 목록 전체가 아니라, 매 순간 처리하는 것은 학생 한 명입니다.

그 한 명을 코드에서는 `student`라고 부를 수 있습니다.

### 질문 4. 반복은 언제 끝나는가?

`students` 안의 학생을 모두 처리하면 끝납니다.

이 네 가지가 보이면 그다음에 `for`를 작성합니다.

---

## 4. 이제 for문을 사람의 말로 읽어 봅시다

다음 코드를 보겠습니다.

```python
for student in students:
    print(student)
```

이 코드를 문법으로만 보지 말고 사람의 말로 바꿔 봅시다.

> `students` 안에 있는 학생을 **한 명씩 꺼내서**, 현재 학생을 `student`라고 부르겠다.

첫 번째 반복에서는:

```python
student = {"name": "민수", "score": 85}
```

두 번째 반복에서는:

```python
student = {"name": "지영", "score": 72}
```

세 번째 반복에서는:

```python
student = {"name": "현우", "score": 91}
```

![List에서 한 장씩 꺼내는 반복 흐름](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter04/list-iteration-flow.jpg)

여기서 아주 중요한 점이 있습니다.

> **`student`는 특정 학생의 이름이 아닙니다.**  
> 반복할 때마다 바뀌는 **현재 처리 중인 학생**입니다.

---

## 5. 반복문 안에서는 현재 한 명만 생각합니다

학생이 100명이라고 생각하면 복잡해 보일 수 있습니다.

하지만 반복문 안에서는 100명을 동시에 처리하지 않습니다.

한 순간에는 항상 한 명만 처리합니다.

```python
for student in students:
    name = student["name"]
    score = student["score"]

    print(name, score)
```

반복문 안에서 우리가 하는 일은 단순합니다.

```text
현재 학생의 이름 확인
현재 학생의 점수 확인
현재 학생의 정보 출력
```

이 작업이 끝나면 다음 학생으로 넘어갑니다.

![반복문 내부에서 한 학생을 처리하는 과정](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter04/loop-inside-zoom.jpg)

따라서 반복을 이해할 때 다음 문장을 기억하면 좋습니다.

> **여러 개를 반복하지만, 한 번에는 하나만 처리한다.**

## 6. 직접 손으로 반복 과정을 추적해 봅시다

코드를 실행하기 전에 손으로 따라가 보겠습니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]

for student in students:
    name = student["name"]
    score = student["score"]
    print(name, score)
```

### 첫 번째 반복

현재 `student`:

```python
{"name": "민수", "score": 85}
```

따라서:

```python
name = "민수"
score = 85
```

출력:

```text
민수 85
```

### 두 번째 반복

현재 `student`:

```python
{"name": "지영", "score": 72}
```

따라서:

```python
name = "지영"
score = 72
```

출력:

```text
지영 72
```

### 세 번째 반복

현재 `student`:

```python
{"name": "현우", "score": 91}
```

따라서:

```python
name = "현우"
score = 91
```

출력:

```text
현우 91
```

이제 목록의 모든 학생을 처리했으므로 반복이 끝납니다.

## 7. 반복문 안의 작업을 하나씩 늘려 봅시다

처음부터 복잡한 코드를 만들 필요는 없습니다.

반복 안의 작업을 조금씩 추가하는 것이 좋습니다.

### 단계 1. 이름만 출력

```python
for student in students:
    print(student["name"])
```

### 단계 2. 이름과 점수 출력

```python
for student in students:
    name = student["name"]
    score = student["score"]

    print(name, score)
```

### 단계 3. 조건까지 추가

```python
for student in students:
    name = student["name"]
    score = student["score"]

    if score >= 80:
        result = "합격"
    else:
        result = "불합격"

    print(name, score, result)
```

이렇게 보면 `for`와 `if`의 역할도 구분할 수 있습니다.

- `for` → 여러 학생에게 같은 작업 반복
- `if` → 현재 학생의 점수를 기준으로 판단

즉 반복과 조건은 서로 다른 역할을 합니다.

## 8. 실행 전에 결과를 예상해 봅시다

다음 코드를 실행하기 전에 출력 결과를 먼저 적어 보세요.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]

for student in students:
    score = student["score"]

    if score >= 80:
        print(student["name"], "합격")
```

먼저 생각합니다.

```text
민수 → ?
지영 → ?
현우 → ?
```

예상 결과:

```text
민수 합격
현우 합격
```

지영은 조건이 거짓이므로 출력되지 않습니다.

이렇게 반복문에서는 **각 항목이 한 번씩 조건을 통과하는 모습**을 머릿속으로 그려 보는 것이 중요합니다.

## 9. 반복문 바깥과 안을 구분해야 합니다

초보자가 자주 하는 실수 중 하나가 들여쓰기입니다.

다음 코드를 보겠습니다.

```python
for student in students:
    name = student["name"]
    score = student["score"]

print(name, score)
```

`print()`가 반복문 바깥에 있습니다.

따라서 반복 중에는 출력하지 않고, 반복이 모두 끝난 뒤 마지막 학생의 값만 출력됩니다.

결과:

```text
현우 91
```

반면 다음 코드는:

```python
for student in students:
    name = student["name"]
    score = student["score"]

    print(name, score)
```

`print()`가 반복문 안에 있으므로 학생마다 실행됩니다.

결과:

```text
민수 85
지영 72
현우 91
```

따라서 반복 문제에서는 항상 질문해야 합니다.

> **이 코드는 학생마다 실행되어야 하는가, 아니면 모든 반복이 끝난 뒤 한 번만 실행되어야 하는가?**

## 10. 변수 이름은 현재 항목의 의미를 보여줘야 합니다

다음 코드는 동작할 수 있습니다.

```python
for x in students:
    print(x["name"])
```

하지만 초보 단계에서는 이런 이름보다 다음이 훨씬 좋습니다.

```python
for student in students:
    print(student["name"])
```

왜냐하면 코드를 읽을 때 의미가 바로 보이기 때문입니다.

```text
students → 여러 학생
student  → 현재 학생 한 명
```

다른 데이터에서도 같은 원칙을 사용할 수 있습니다.

```python
for order in orders:
```

```python
for product in products:
```

```python
for message in messages:
```

반복 변수는 **현재 처리 중인 한 개가 무엇인지** 드러내는 이름이 좋습니다.

## 11. 반복이 필요한 문제인지 먼저 판단해 봅시다

아래 문제마다 반복이 필요한지 먼저 생각해 보세요.

### 문제 A

학생 한 명의 점수가 80점 이상인지 확인한다.

→ 학생이 한 명이므로 반드시 반복이 필요한 것은 아닙니다.

### 문제 B

학생 30명의 이름을 모두 출력한다.

→ 여러 학생에게 같은 출력 작업을 해야 하므로 반복이 자연스럽습니다.

### 문제 C

주문 50건 중 각 주문 금액을 출력한다.

→ 여러 주문에게 같은 작업을 하므로 반복이 필요합니다.

### 문제 D

오늘의 최고 기온 하나를 출력한다.

→ 이미 하나의 값이 주어졌다면 반복이 필요하지 않을 수 있습니다.

즉 `for`를 쓸지 말지는 문법 문제가 아니라 **데이터와 작업의 구조 문제**입니다.

## 16. 전이 연습 — 이번에는 주문 데이터입니다

이제 학생이 아닌 쇼핑몰 주문을 보겠습니다.

```python
orders = [
    {"customer": "민수", "amount": 32000},
    {"customer": "지영", "amount": 58000},
    {"customer": "현우", "amount": 71000}
```

```text
students → orders
student  → order
```

```python
for order in orders:
```

여기서 중요한 것은 코드를 외우는 것이 아닙니다.

> **여러 주문에 같은 일을 해야 한다는 반복 구조를 발견했는가?**

이것이 핵심입니다.

## 17. 데이터베이스와 데이터 분석에서도 같은 생각을 합니다

앞으로 데이터베이스와 데이터 분석을 배우면 수백 개, 수천 개, 수백만 개의 데이터를 다루게 됩니다.

그때도 기본 질문은 같습니다.

```text
데이터가 여러 개인가?
각 데이터에 무엇을 해야 하는가?
어떤 데이터만 선택해야 하는가?
무엇을 계산해야 하는가?
```

Python에서는 `for`를 통해 이런 구조를 직접 경험합니다.

나중에는 SQL이나 pandas가 많은 반복 작업을 더 간결하게 처리해 주지만, 그 안의 사고는 연결되어 있습니다.

예를 들어:

```python
for student in students:
    if student["score"] >= 80:
        print(student)
```

이 사고는 나중에 SQL의 `WHERE`나 pandas의 필터링으로 이어집니다.

따라서 지금 배우는 반복은 단순히 Python 문법 하나가 아닙니다.

**여러 데이터를 순서대로 처리하는 데이터 사고의 기초**입니다.

## 18. AI를 사용하기 전에 반드시 스스로 답해야 할 질문

이번 Chapter에서도 처음부터 AI에게 코드를 요청하지 않습니다.

먼저 다음 질문에 자신의 말로 답하세요.

```text
1. 여러 개인 데이터는 무엇인가?
2. 현재 한 개는 무엇인가?
3. 모든 데이터에 반복할 작업은 무엇인가?
4. 반복 안에 조건이 필요한가?
5. 반복이 끝나면 무엇이 남아야 하는가?
```

이 다섯 질문에 답한 뒤 직접 코드를 작성합니다.

코드를 실행하고 예상과 비교한 다음, 필요하면 Python 공식 문서를 확인합니다.

AI는 마지막에 다음과 같은 용도로 사용합니다.

- 내가 찾은 반복 구조가 적절한지 검토
- 변수 이름이 이해하기 좋은지 검토
- 더 단순한 표현이 있는지 확인
- 내가 놓친 예외 상황이 있는지 확인

> **AI에게 반복문을 만들어 달라고 하기 전에, 무엇이 반복되는지는 내가 먼저 찾아야 합니다.**

## 19. 이번 Chapter에서 자주 하는 실수

### 실수 1. 여러 데이터라는 이유만으로 무조건 for를 쓴다

먼저 정말 같은 작업을 반복해야 하는지 확인해야 합니다.

### 실수 2. `student`를 특정 학생이라고 생각한다

`student`는 반복마다 바뀌는 현재 학생입니다.

### 실수 3. 반복문 안에 들어갈 코드 범위를 잘못 잡는다

학생마다 실행해야 하는 코드는 들여쓰기를 통해 반복문 안에 둡니다.

### 실수 4. 코드를 실행하면서만 이해하려고 한다

실행 전에 민수 → 지영 → 현우 순서로 손으로 추적해 보세요.

### 실수 5. 데이터가 늘어날 때 코드를 복사해서 붙여 넣는다

같은 코드가 반복되기 시작한다면 반복 구조를 먼저 의심해야 합니다.

