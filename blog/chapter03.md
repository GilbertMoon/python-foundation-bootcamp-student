# Chapter 03·04 통합 실습 — 요구사항을 프로그램 구조와 수도코드로 바꾸기

> **이번 실습의 목표는 Python 코드를 빨리 작성하는 것이 아닙니다.**  
> 실제 요구사항을 읽고 스스로 **데이터 / 반복 / 조건 / 처리 / 결과**를 찾아낸 뒤,  
> Chapter 03의 **판단 기준·경계값·조건 순서**와 Chapter 04의 **반복 대상·현재 항목·반복 범위**를 결합하여  
> **Python 코드를 작성하기 직전 단계인 수도코드까지 완성하는 것**이 목표입니다.

---

# 0. 이번 실습에서 가장 먼저 바꿔야 하는 습관

문제를 읽자마자 다음과 같이 생각하지 않습니다.

```text
for를 써야 하나?
if를 써야 하나?
elif가 필요한가?
and를 써야 하나?
```

이번에는 반드시 다음 순서로 생각합니다.

```text
요구사항 읽기
↓
무엇을 최종적으로 만들어야 하는지 확인
↓
데이터 찾기
↓
반복 찾기
↓
조건 찾기
↓
처리할 내용 찾기
↓
결과 정의
↓
판단 대상 / 기준값 / 경계값 찾기
↓
조건 검사 순서 정하기
↓
반복 대상 / 현재 한 개 / 반복 작업 찾기
↓
예상 결과 작성
↓
수도코드 작성
↓
그 다음에 Python 코드 작성
```

> **이번 실습에서는 세 문제 모두 수도코드까지 작성하면 1차 목표를 달성한 것입니다.**

---

# 1. 요구사항을 읽을 때 사용하는 기본 5칸

앞으로 모든 문제에서 가장 먼저 다음 다섯 항목을 작성합니다.

```text
데이터:
반복:
조건:
처리:
결과:
```

각 항목은 다음 질문으로 찾습니다.

| 항목 | 스스로에게 할 질문 |
|---|---|
| 데이터 | 어떤 정보가 주어졌는가? |
| 반복 | 여러 개인 것은 무엇이며, 무엇을 하나씩 확인해야 하는가? |
| 조건 | 어떤 경우 결과가 달라지는가? |
| 처리 | 비교, 계산, 변경, 선택 등 무엇을 해야 하는가? |
| 결과 | 마지막에 무엇을 출력하거나 남겨야 하는가? |

중요한 점은 **문장에 직접 쓰여 있지 않은 반복과 조건도 직접 찾아야 한다는 것**입니다.

예를 들어 `가장 큰 값을 구한다`라는 요구사항에는 `if`라는 단어가 없지만 실제로는 다음 생각이 필요합니다.

```text
현재 값이 지금까지의 가장 큰 값보다 큰가?
```

이처럼 **요구사항 문장을 프로그램이 실행할 수 있는 구조로 바꾸는 것**이 이번 실습의 핵심입니다.

# 2. Chapter 03에서 반드시 적용할 조건 분석

조건이 있는 문제에서는 다음 내용을 추가로 작성합니다.

```text
판단 대상:
기준값:
비교 관계:
결과가 바뀌는 경계값:
조건 검사 순서:
```

조건을 분석할 때 다음 표현을 정확하게 구분합니다.

| 문제 표현 | 생각해야 할 비교 |
|---|---|
| 이상 | 기준값 포함 |
| 초과 | 기준값 제외 |
| 이하 | 기준값 포함 |
| 미만 | 기준값 제외 |
| 같다 | 같은 값인지 판단 |
| 같지 않다 | 다른 값인지 판단 |
| 둘 다 만족 | `and` 관계 |
| 둘 중 하나라도 만족 | `or` 관계 |

Python 기호를 먼저 쓰는 것이 아니라 **문장의 의미를 먼저 설명할 수 있어야 합니다.**

# 3. Chapter 04에서 반드시 적용할 반복 분석

반복이 있는 문제에서는 다음 내용을 추가로 작성합니다.

```text
여러 개인 데이터:
현재 처리 중인 한 개:
각 데이터마다 반복할 작업:
반복 안에 들어가야 하는 판단:
반복이 끝나는 시점:
반복이 끝난 뒤 한 번만 해야 하는 작업:
```

특히 다음 질문을 꼭 합니다.

> **이 작업은 각 데이터마다 실행되어야 하는가, 아니면 모든 반복이 끝난 뒤 한 번만 실행되어야 하는가?**

반복문 안과 밖을 구분하는 사고가 중요합니다.

# 4. 경계값 테스트 방법

조건을 찾았으면 코드 작성 전에 테스트할 값을 먼저 정합니다.

기준값이 `80`이라면 최소한 다음 세 값을 생각합니다.

```text
79
80
81
```

기준값이 여러 개라면 각 기준의 바로 아래, 기준값 자체, 바로 위를 확인합니다.

예를 들어 기준값이 `80`, `90`이라면:

```text
79, 80, 81
89, 90, 91
```

모든 숫자를 테스트하는 것이 아니라 **결과가 바뀌는 지점을 집중적으로 확인하는 것**이 목적입니다.

# 5. 수도코드는 Python 문법이 아닙니다

수도코드는 사람이 이해할 수 있는 말로 **컴퓨터가 실행할 순서를 적은 것**입니다.

좋은 수도코드는 다음 특징을 가집니다.

```text
한 단계에 한 가지 의미 있는 작업만 있다.
실행 순서가 보인다.
반복되는 부분이 보인다.
조건이 어디에서 사용되는지 보인다.
최종 결과가 언제 만들어지는지 보인다.
```

수도코드에서는 Python의 괄호, 콜론, 정확한 변수명까지 맞출 필요가 없습니다.

이번 실습에서는 **Python 코드로 번역할 수 있을 정도로 구체적인 수도코드**를 만드는 것이 목표입니다.

# 실습 2 — 난이도 중

# 7. 쇼핑몰 주문의 배송 등급 결정하기

## 요구사항

다음 주문 정보가 있습니다.

| 고객 | 주문금액 | 회원등급 |
|---|---:|---|
| 민수 | 49,000 | 일반 |
| 지영 | 50,000 | VIP |
| 현우 | 99,000 | 일반 |
| 수빈 | 100,000 | VIP |
| 원빈 | 120,000 | 일반 |

모든 주문을 하나씩 확인하고 다음 기준으로 배송 결과를 정합니다.

- 주문금액이 100,000원 이상이면서 회원등급이 `VIP`이면 `VIP 우선배송`
- 그렇지 않더라도 주문금액이 50,000원 이상이거나 회원등급이 `VIP`이면 `무료배송`
- 나머지는 `일반배송`
- 모든 고객의 고객명, 주문금액, 회원등급, 배송 결과를 확인할 수 있어야 합니다.

---

## STEP 1. 요구사항에서 프로그램 구조 찾기

```markdown
### 문제 구조

- 데이터:
- 반복:
- 조건:
- 처리:
- 결과:
```

이번 문제에서는 `학생`, `점수`라는 단어가 없습니다.

하지만 실습 1과 같은 구조가 있는지 생각합니다.

## STEP 2. 판단 대상이 몇 개인지 찾기

```markdown
### 판단에 사용되는 정보

- 판단 대상 1:
- 판단 대상 2:
```

그리고 두 값의 관계를 문제 문장에서 찾습니다.

```markdown
### 논리 관계

- 두 조건을 모두 만족해야 하는 경우:
- 두 조건 중 하나라도 만족하면 되는 경우:
```

여기에서 Chapter 03의 `and`, `or` 개념을 연결합니다.

---

## STEP 3. 조건 순서 분석

다음 두 결과는 조건이 겹칠 수 있습니다.

```text
VIP 우선배송

```

다음 질문에 답합니다.

```markdown
### 조건 순서

1. 가장 먼저 검사할 조건:
2. 그 다음 검사할 조건:

```

> 조건은 위에서 아래로 검사하며, 처음 만족한 결과에서 판단이 끝날 수 있다는 점을 기억합니다.

## STEP 8. 수도코드 작성

다음 구조를 참고하여 실제 조건을 자신의 말로 채웁니다.

```text

    현재 주문의 정보와 배송 결과를 보여준다

모든 주문을 처리하면 끝낸다
```

정확한 Python 문법은 아직 작성하지 않습니다.

# 8. 상품 상태와 추천 여부 함께 판단하기

## 요구사항

다음 상품 정보가 있습니다.

| 상품명 | 평점 | 재고 | 판매상태 |
|---|---:|---:|---|
| 키보드 | 4.8 | 12 | 판매중 |
| 마우스 | 4.6 | 3 | 판매중 |
| 모니터 | 4.2 | 0 | 판매중 |
| 헤드셋 | 4.9 | 8 | 판매중지 |
| 웹캠 | 3.8 | 10 | 판매중 |

모든 상품을 하나씩 확인하여 다음 기준으로 상품 결과를 정합니다.

- 판매상태가 `판매중`이 아니거나 재고가 0 이하이면 `판매불가`
- 위 조건에 해당하지 않으면서 평점이 4.5 이상이고 재고가 5개 이상이면 `추천`
- 위 조건에 해당하지 않으면서 평점이 4.0 이상이면 `일반`
- 나머지는 `관심 필요`
- 모든 상품의 상품명, 평점, 재고, 판매상태, 결과를 확인할 수 있어야 합니다.

이번 문제에서는 이전 문제보다 힌트를 줄입니다.

# 13. 다음 시간까지 반드시 외워 올 코드

아래 코드는 이번 세 문제의 정답 코드가 아닙니다.

students = [
    {"name": "민수", "score": 85, "attendance": 92},

    {"name": "현우", "score": 91, "attendance": 78},

selected_students = []

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    if score >= 80 and attendance >= 80:
        selected_students.append(student)

for student in selected_students:
    print(
        f"{student['name']}: "
        f"점수 {student['score']}점, "
        f"출석률 {student['attendance']}%"
