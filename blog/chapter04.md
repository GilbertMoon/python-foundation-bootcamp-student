```text

→ 필터링

→ 데이터 구조 설계
```

실제 문제에서는 이 세 가지가 함께 등장합니다.

예를 들어:

```text
여러 학생이 있다.
각 학생은 이름, 점수, 출석률을 가진다.
점수와 출석률이 기준 이상인 학생만 골라낸다.

```

이 한 문장 안에는 이미 다음 구조가 모두 들어 있습니다.

```text
학생 한 명의 속성 표현   → Dictionary
여러 학생 묶기           → List
모든 학생 확인           → 반복
조건에 맞는 학생 고르기 → 필터링
선택된 학생 수 계산      → 개수 집계
선택된 학생 점수 합계    → 합계 집계
평균 계산                → 합계 ÷ 개수
```

# 3. Chapter 05 — 필터링을 찾는 질문

필터링 문제에서는 다음 세 가지를 찾습니다.

```text
① 무엇을 모두 확인해야 하는가?
② 어떤 조건으로 선택할 것인가?
③ 선택한 결과를 어떻게 사용할 것인가?
```

필터링의 핵심 흐름은 다음입니다.

```text
모두 확인한다
↓
현재 항목을 판단한다
↓
조건을 통과하면 선택한다
↓
필요하면 새로운 List에 저장한다
```

중요한 구분:

```text
확인한다 ≠ 선택한다
```

결과에 포함되지 않는 데이터도 **반드시 확인한 뒤 제외**하는 것입니다. Chapter 05의 핵심은 반복과 조건을 결합해 필요한 데이터만 고르는 것입니다.

---

# 4. Chapter 06 — 집계를 찾는 질문

집계 문제에서는 다음 질문을 합니다.

```text
① 무엇을 계속 기억해야 하는가?
② 시작값은 무엇인가?
③ 반복할 때마다 어떻게 값을 갱신하는가?
④ 반복이 끝난 뒤 무엇을 계산하는가?
```

대표적인 집계는 다음과 같습니다.

```text
합계   → 값을 계속 더한다
개수   → 조건을 만족할 때 1씩 증가한다
평균   → 합계와 개수가 완성된 뒤 나눈다
최댓값 → 현재 최고값과 비교해 필요하면 교체한다
```

집계 문제에서는 특히 다음 질문이 중요합니다.

> **이 변수는 반복할 때마다 새로 시작해야 하는가, 아니면 이전 결과를 계속 기억해야 하는가?**

합계, 개수, 최고값처럼 이전 결과를 기억해야 하는 값은 보통 반복 전에 준비합니다.

# 5. Chapter 07 — 데이터 구조를 찾는 질문

코드부터 만들기 전에 현실의 구조를 먼저 봅니다.

```text
① 현실의 대상은 무엇인가?
② 대상 하나가 가지는 속성은 무엇인가?
③ 속성마다 이름이 필요한가?
④ 같은 종류의 대상이 여러 개인가?
⑤ 이후 어떤 작업을 해야 하는가?
```

기본 연결은 다음과 같습니다.

```text
대상 한 개 + 여러 이름 있는 속성
→ Dictionary

같은 종류의 대상 여러 개
→ List of Dictionaries
```

예:

```text
상품 한 개
- 상품명
- 가격
- 재고
- 카테고리

상품 여러 개
→ 같은 구조의 Dictionary 여러 개를 List로 묶기
```

# 15. 다음 시간까지 직접 입력하고 암기할 코드

아래 코드는 **이번 세 실습의 정답 코드가 아닙니다.**

다음 Chapter에서 사용할 기본 구조를 미리 익히기 위한 준비 코드입니다.

복사해서 붙여 넣지 말고 직접 입력하세요.

```python
students = [
    {"name": "민수", "score": 85, "attendance": 92},
    {"name": "지영", "score": 72, "attendance": 88},
    {"name": "현우", "score": 91, "attendance": 97},
    {"name": "서연", "score": 84, "attendance": 75}
]

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    if score >= 90:
        result = "우수"
    elif score >= 80 and attendance >= 80:
        result = "수료"
    else:
        result = "보완 필요"

    print(name, score, attendance, result)
```

이 코드는 Chapter 08에서 다루는 **여러 데이터 + 여러 조건 + 조건 우선순위**의 기본 구조입니다.
