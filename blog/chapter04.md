# 0. 이번 실습에서 가장 중요한 규칙

이번 실습에는 **문제의 Python 정답 코드를 제공하지 않습니다.**

문제를 읽자마자 다음과 같이 생각하지 않습니다.

```text
for를 어떻게 쓰지?
if를 어떻게 쓰지?
append()를 어디에 쓰지?
```

먼저 다음 순서로 생각합니다.

```text
요구사항 읽기
↓
문제를 내 말로 다시 설명
↓
현실의 대상과 속성 찾기
↓
대상 하나와 여러 대상을 표현할 자료구조 결정
↓
데이터 / 반복 / 조건 / 처리 / 결과 찾기
↓
필터링이 필요한지 확인
↓
집계가 필요한지 확인
↓
반복 전에 준비할 값 찾기
↓
반복 중 갱신할 값 찾기
↓
반복 후 계산할 값 찾기
↓
실행 전 예상
↓
손으로 실행 추적
↓
수도코드 작성
↓
마지막에 Python 코드 작성
```

> **코드는 마지막에 작성합니다.**  
> 이번 실습의 핵심은 문제를 보고 필요한 구조를 스스로 만들어 내는 것입니다.


## Chapter 07 — 데이터 구조 설계

현실의 대상을 Python 구조로 표현합니다.

```text
대상 한 개
+
이름이 있는 여러 속성
→ Dictionary

같은 종류의 대상 여러 개
→ List of Dictionaries
```

예를 들어 학생 한 명에게 이름, 점수, 출석률이 있다면 각 값은 서로 관련된 하나의 학생 정보입니다.

```text
학생 한 명의 Dictionary → 표의 한 행(row)
Dictionary의 key          → 표의 열(column)
학생 여러 명의 List       → 여러 행으로 이루어진 표
```

# 2. 문제를 읽을 때 가장 먼저 작성할 5칸

모든 문제에서 가장 먼저 다음 다섯 항목을 작성합니다.

```text
데이터:
반복:
조건:
처리:
결과:
```

| 항목 | 스스로에게 할 질문 |
|---|---|
| 데이터 | 어떤 대상과 어떤 속성이 주어졌는가? |
| 반복 | 여러 개인 것은 무엇이며 무엇을 하나씩 확인해야 하는가? |
| 조건 | 어떤 데이터를 선택하거나 제외해야 하는가? |
| 처리 | 무엇을 저장·누적·비교·계산해야 하는가? |
| 결과 | 마지막에 어떤 목록이나 숫자가 남아야 하는가? |

문장에 `for`나 `if`라는 단어가 없어도 반복과 조건이 숨어 있을 수 있습니다.

예를 들어:

```text
가장 높은 가격을 구한다.
```

라는 요구사항에는 `if`라는 말이 없지만 실제 해결 과정에는 다음 사고가 필요합니다.

```text
현재 가격이 지금까지의 최고 가격보다 큰가?
```

즉 **요구사항에 직접 적혀 있지 않은 조건도 문제 해결 과정에서 스스로 만들어야 합니다.**


# 4. 집계 문제에서 사용할 질문

합계, 개수, 평균, 최고값이 보이면 다음을 적습니다.

```text
무엇을 계속 기억해야 하는가?
초기값은 무엇인가?
어느 경우에 갱신하는가?
어떻게 갱신하는가?
반복이 끝난 뒤 무엇을 계산하는가?
```

대표적인 사고는 다음과 같습니다.

```text
합계
→ 현재 합계에 현재 값을 더한다.

개수
→ 필요한 데이터를 발견할 때 1 증가시킨다.

평균
→ 필요한 합계와 개수가 모두 준비된 뒤 계산한다.

최고값
→ 현재 값과 지금까지의 최고값을 비교해 필요하면 교체한다.
```

`sum()`, `max()`, pandas 집계 기능처럼 결과를 바로 만들어 주는 도구보다 **직접 반복하면서 값이 어떻게 변하는지 이해하는 것**을 우선합니다.

# 5. 반복 전 / 반복 중 / 반복 후를 구분합니다

집계 문제가 어려워지는 가장 큰 이유 중 하나는 코드의 위치를 구분하지 못하기 때문입니다.

항상 다음 세 영역으로 나눠 적습니다.

```text
[반복 전]
한 번만 준비해야 하는 것은 무엇인가?

[반복 중]
현재 데이터마다 반복해야 하는 것은 무엇인가?

[반복 후]
모든 데이터 처리가 끝난 뒤 한 번만 해야 하는 것은 무엇인가?
```

예를 들어 평균 문제라면 보통 다음 관계가 있습니다.

```text
반복 전
→ 합계와 개수를 저장할 값 준비

반복 중
→ 합계와 개수 갱신

반복 후
→ 평균 계산
```

정확한 변수 이름과 Python 코드는 학생이 직접 결정합니다.

```python
students = [
    {"name": "민수", "score": 85, "attendance": 92},
    {"name": "지영", "score": 72, "attendance": 88},
    {"name": "현우", "score": 91, "attendance": 97},
    {"name": "서연", "score": 84, "attendance": 75}
]

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    if score >= 90 and attendance >= 80:
        result = "우수"
    elif score >= 80 and attendance >= 80:
        result = "수료"
    else:
        result = "보완 필요"

    print(name, score, attendance, result)
```

# 24. 이번 통합 실습의 한 문장

> **현실의 여러 데이터를 구조로 표현하고, 하나씩 확인하고, 필요한 데이터만 선택하고, 선택된 값들을 누적·비교하여 새로운 결과를 만든다.**

Chapter 05·06·07의 핵심은 `for`, `if`, `append()` 같은 문법을 따로 외우는 것이 아닙니다.

```text
문제를 읽는다
↓
데이터 구조를 찾는다
↓
모두 확인한다
↓
필요한 것을 선택한다
↓
결과를 저장한다
↓
값을 누적하거나 비교한다
↓
마지막 결과를 계산한다
```

이 흐름을 스스로 만들 수 있다면 다음 Chapter의 복합 요구사항도 훨씬 쉽게 다룰 수 있습니다.
