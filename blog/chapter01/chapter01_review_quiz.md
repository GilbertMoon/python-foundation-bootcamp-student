# 1. 이번 퀴즈의 학습 목표

퀴즈를 마치면 다음을 스스로 설명할 수 있어야 합니다.

- DataFrame에 어떤 데이터가 들어 있는지 확인할 수 있다.
- DataFrame의 전체 데이터를 Python 기본 자료구조로 받아 처리할 수 있다.
- 여러 데이터를 `for`로 하나씩 순회할 수 있다.

# 2. 가장 중요한 규칙 — 문제 해결에는 pandas 사용 금지

이번 퀴즈에서는 **데이터를 준비하는 첫 번째 셀까지만 pandas를 사용합니다.**

아래 준비 코드는 그대로 실행합니다.

이 셀에서는 CSV를 DataFrame으로 읽고, 컬럼명을 일부러 대문자가 포함된 형태로 바꾼 뒤, DataFrame의 내용을 Python 기본 자료구조로 꺼내 줍니다.

```python
import pandas as pd

url = "https://raw.githubusercontent.com/GilbertMoon/llm-data-analysis-course/main/data/raw/customers.csv"

df = pd.read_csv(url)

df.columns = [
    "Customer_ID",
    "Name",
    "Gender",
    "Age",
    "City",
    "Signup_Date"
]

records = df.to_dict(orient="records")
columns = list(df.columns)

print(df.head())
```

> **위 셀은 데이터 준비용으로 제공되는 코드입니다.**  
> 이 셀 아래부터 학생이 작성하는 문제 해결 코드에서는 pandas 기능을 사용하지 않습니다.

이후에는 다음 두 변수만 사용해서 문제를 해결합니다.

```text
records  → 전체 고객 데이터가 들어 있는 List
columns  → 전체 컬럼명이 들어 있는 List
```

`records` 안의 고객 한 명은 Dictionary입니다.

즉 Chapter 01에서 계속 연습했던 구조와 같습니다.

```text
List
↓
Dictionary 여러 개
↓
for로 하나씩 확인
↓
필요한 값 꺼내기
↓
조건 판단 / 값 누적
↓
결과 만들기
```

# 3. 사용 금지 기능

이번 퀴즈는 Python의 기본 반복과 조건을 직접 사용하는 것이 목적입니다.

따라서 학생이 작성하는 문제 해결 코드에서는 다음 기능을 사용하지 않습니다.

```text
× df["Age"].sum()
× df["Age"].mean()
× df["Signup_Date"].max()
× df["Signup_Date"].min()
× df.describe()
× df.columns.str.lower()
× Series 또는 DataFrame의 집계 기능
× max()
× min()
× sum()
× statistics.mean()
```

AI에게 다음을 요청해서도 안 됩니다.

```text
× 정답 코드 작성
× 완성 코드 작성
× 수도코드 대신 작성
× 최대/최소를 구하는 로직 대신 작성
× 평균을 구하는 로직 대신 작성
× 내 코드를 수정해서 정답으로 만들어 달라는 요청
```

이번 퀴즈에서는 **반복문, 변수, 조건문을 이용해 직접 결과를 만들어야 합니다.**

# 4. 최종 문제

준비된 `records`와 `columns`를 이용하여 다음 요구사항을 모두 해결하세요.

## 요구사항 1 — 전체 데이터를 순회한다

`records` 안에 있는 모든 고객을 한 명씩 확인합니다.

```text
첫 번째 고객
↓
두 번째 고객
↓
세 번째 고객
↓
...
↓
마지막 고객
```

어떤 반복문을 사용할지는 직접 결정하세요.

---

## 요구사항 2 — 가입일의 최댓값과 최솟값을 구한다

사용할 날짜 컬럼은 다음입니다.

```text
Signup_Date
```

모든 고객의 가입일을 하나씩 확인하여 다음 두 값을 직접 구합니다.

```text
가장 오래된 가입일
가장 최근 가입일
```

날짜는 다음과 같은 형식입니다.

```text
YYYY-MM-DD
```

예:

```text
2024-06-19
2025-11-02
2026-04-13
```

이번 데이터처럼 날짜 형식이 모두 `YYYY-MM-DD`로 동일하면 문자열 비교를 이용해 날짜의 앞뒤를 판단할 수 있습니다.

하지만 **어떤 변수로 시작하고, 반복하면서 어떤 경우에 값을 바꿀지는 직접 생각해야 합니다.**

`max()`와 `min()`은 사용하지 않습니다.

---

## 요구사항 3 — 나이의 합계와 평균을 구한다

사용할 숫자 컬럼은 다음입니다.

```text
Age
```

모든 고객의 나이를 하나씩 확인하여 다음 값을 구합니다.

```text
전체 나이 합계
전체 나이 평균
```

`sum()`과 pandas의 `mean()`은 사용하지 않습니다.

먼저 다음 질문에 자신의 말로 답해 보세요.

```text
현재 고객의 나이를 어디에 계속 더할 것인가?
현재까지 몇 명을 확인했는지 어떻게 기억할 것인가?
모든 반복이 끝난 뒤 평균을 어떻게 계산할 것인가?
```

---

## 요구사항 4 — 모든 컬럼명을 소문자로 만든다

현재 컬럼명은 다음과 같습니다.

```text
Customer_ID
Name
Gender
Age
City
Signup_Date
```

`columns`의 모든 컬럼명을 하나씩 확인해서 **새로운 소문자 컬럼명 List**를 만듭니다.

최종 형태는 다음과 같아야 합니다.

```text
customer_id
name
gender
age
city
signup_date
```

다음 방식은 사용하지 않습니다.

```text
× df.columns.str.lower()
```

문자열 하나를 소문자로 만드는 Python 문자열 기능 `lower()`는 사용할 수 있습니다.

먼저 다음을 생각해 보세요.

```text
새 컬럼명을 어디에 저장할 것인가?
컬럼명을 무엇으로 하나씩 반복할 것인가?
현재 컬럼명을 소문자로 바꾼 뒤 어디에 추가할 것인가?
```

```markdown
- 아직 헷갈리는 부분:
```

# 13. 새롭게 공부한 내용을 바로 기록

이번 퀴즈에서는 **모르는 것을 만났다는 사실이 감점 요소가 아닙니다.**

```markdown
- Python 공식 문서 / 수업 자료 / AI / 기타

### 확인 후 내가 이해한 내용

### 이 내용을 실제 코드의 어느 부분에 사용했는가?
```

새로운 내용이 또 나오면 `추가 학습 기록 2`, `추가 학습 기록 3`처럼 계속 작성합니다.

# 14. 아직도 이해가 안 되는 부분을 기록

모든 것을 이해한 것처럼 작성할 필요는 없습니다.

과제를 마친 뒤에도 이해되지 않는 부분이 있다면 그대로 남깁니다.

```markdown
## 아직 이해가 안 되는 부분

### 항목 1
- 이해되지 않는 내용:
- 어디까지는 이해했는가:
- 정확히 어느 부분부터 모르겠는가:

### 항목 2
- 이해되지 않는 내용:
- 어디까지는 이해했는가:
- 정확히 어느 부분부터 모르겠는가:
```

없다면 다음처럼 작성합니다.

```markdown
## 아직 이해가 안 되는 부분

현재까지는 없음.
```

# 15. AI 사용 규칙

이번 퀴즈에서는 AI 사용을 허용합니다.

하지만 AI가 문제를 대신 풀어서는 안 됩니다.

## AI에게 물어봐도 되는 질문

다음과 같은 질문은 가능합니다.

```text
"Python에서 변수에 값을 누적한다는 것이 어떤 의미인지 코드 없이 설명해 주세요."

"문자열 lower()의 역할을 아주 간단한 별도 예제로 설명해 주세요. 이번 퀴즈 정답은 작성하지 마세요."

"for 반복문의 동작 원리를 이번 문제의 정답 코드 없이 설명해 주세요."

"YYYY-MM-DD 형식의 문자열 비교가 왜 날짜 순서와 맞을 수 있는지 설명해 주세요."

"이 오류 메시지가 무슨 뜻인지 설명만 해 주세요. 수정 코드는 작성하지 마세요."
```

## AI에게 물어보면 안 되는 질문

다음은 금지합니다.

```text
"이 퀴즈 풀어 주세요."

"정답 코드 작성해 주세요."

"날짜 최대/최소 구하는 코드 알려 주세요."

"나이 평균 구하는 코드 작성해 주세요."

"전체 수도코드를 만들어 주세요."

"내 코드를 고쳐서 정답으로 만들어 주세요."

"이 요구사항을 만족하는 for문을 작성해 주세요."
```

> AI에게 문제 전체를 붙여 넣고 해결 방법, 수도코드 또는 정답 구조를 요구하는 것도 금지합니다.

# 17. AI를 사용했다면 Notebook에도 기록

# 21. 사용한 AI 채팅 공유 URL 만들기

AI를 사용했다면 과제에 사용한 대화의 **공유 URL**도 함께 제출합니다.

서비스마다 버튼 이름은 조금 다를 수 있지만 일반적인 순서는 다음과 같습니다.

```text
1. 과제에 사용한 AI 대화를 연다.
2. Share / 공유 / 링크 공유 기능을 찾는다.
3. 공유 링크를 생성한다.
4. 생성된 URL을 복사한다.
5. 공유 가능한 링크인지 확인한다.
6. Notebook 마지막 제출 정보에 URL을 붙여 넣는다.
```

여러 개의 AI 대화를 사용했다면 **사용한 모든 대화 URL을 제출**합니다.

```text
AI 채팅 1: https://...
AI 채팅 2: https://...
```

AI를 사용하지 않았다면 공유 URL을 만들 필요가 없습니다.

```text
AI 사용: 없음
```

> 공유 링크를 만들기 전에 대화 안에 비밀번호, API Key, 전화번호, 개인 식별 정보 등 공개하면 안 되는 정보가 없는지 반드시 확인하세요.

# 25. 이번 퀴즈에서 가장 중요한 것

이번 문제의 핵심은 정답 숫자가 아닙니다.

다음 과정을 스스로 경험하는 것이 목적입니다.

```text
문제를 읽는다
↓
무엇을 구해야 하는지 찾는다
↓
데이터를 확인한다
↓
작업 순서를 정한다
↓
수도코드를 작성한다
↓
작은 코드부터 직접 작성한다
↓
반복하면서 값을 비교하고 누적한다
↓
결과를 확인한다
↓
모르는 것을 기록한다
↓
필요한 경우에만 AI에게 질문한다
↓
내가 작성한 결과와 학습 과정을 함께 제출한다
```

> **코드를 작성할 수 있는 것보다, 왜 그렇게 작성했는지 설명할 수 있는 것이 더 중요합니다.**

Chapter 01에서 배운 내용을 실제 데이터 분석 문제에 연결해 보는 것이 이번 퀴즈의 목표입니다.
