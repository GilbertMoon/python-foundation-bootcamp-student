# Chapter 05. 조건과 반복을 결합하면 실제 문제가 풀리기 시작한다

> **이번 Chapter의 핵심은 `for`와 `if` 문법을 따로 외우는 것이 아닙니다.**  
> 여러 데이터를 하나씩 확인하면서 **조건에 맞는 데이터만 골라내는 필터링 사고**를 익히는 것이 목표입니다.

---

## 이제부터 실제 문제처럼 보이기 시작합니다

앞선 Chapter에서 우리는 두 가지 중요한 생각을 배웠습니다.

- Chapter 03: **무엇을 기준으로 판단할 것인가?**
- Chapter 04: **여러 데이터에 같은 일을 반복해야 하는가?**

이번에는 이 두 가지를 결합합니다.

예를 들어 학생 목록에서 다음과 같은 문제를 해결한다고 생각해 봅시다.

> **80점 이상인 학생만 찾아서 이름을 출력하세요.**

이 문제에는 두 가지 일이 동시에 필요합니다.

1. 모든 학생을 한 명씩 확인해야 합니다. → **반복**
2. 현재 학생이 80점 이상인지 판단해야 합니다. → **조건**

즉 문제 해결 구조는 다음과 같습니다.

```text
모든 학생을 확인한다
        ↓
현재 학생의 점수를 본다
        ↓
80점 이상인지 판단한다
        ↓
맞으면 선택한다
        ↓
다음 학생으로 이동한다
```

이 패턴을 **필터링(Filtering)**이라고 생각하면 됩니다.

> **모두 확인한다 → 각각 판단한다 → 필요한 것만 선택한다.**

## 1. 먼저 학생 데이터를 다시 봅시다

이번에도 0강부터 계속 사용한 학생 데이터를 사용합니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]
```

조건은 다음과 같습니다.

```text
점수가 80점 이상인 학생만 선택한다.
```

학생별로 먼저 손으로 판단해 봅시다.

```text
민수 85 → 선택
지영 72 → 선택하지 않음
현우 91 → 선택
```

![학생 데이터 필터링](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter05/student-filter-flow.jpg)

여기서 중요한 점이 있습니다.

지영은 최종 결과에 포함되지 않지만, **지영을 확인하지 않은 것은 아닙니다.**

우리는 세 학생을 모두 확인했습니다.

```text
민수 확인 → 조건 통과
지영 확인 → 조건 탈락
현우 확인 → 조건 통과
```

따라서 필터링 문제에서는 항상 다음 질문을 해야 합니다.

> **결과에 포함되지 않는 데이터도 확인해야 하는가?**

대부분의 필터링 문제에서는 **예, 확인해야 합니다.**

## 2. 반복과 조건의 역할을 분리해서 생각합니다

다음 코드를 보겠습니다.

```python
for student in students:
    if student["score"] >= 80:
        print(student["name"])
```

코드는 짧지만 두 가지 역할이 분명하게 나뉩니다.

### `for`의 역할

```python
for student in students:
```

학생 목록을 한 명씩 확인합니다.

즉:

```text
민수 → 지영 → 현우
```

### `if`의 역할

```python
if student["score"] >= 80:
```

현재 학생이 결과에 포함될지 판단합니다.

즉:

```text
현재 학생 점수 >= 80 ?
```

### `print()`의 역할

```python
print(student["name"])
```

조건을 통과한 학생만 출력합니다.

따라서 전체 구조는 다음과 같습니다.

```text
반복 → 판단 → 선택
```

![반복과 조건을 결합한 필터링 흐름](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter05/loop-condition-filter.jpg)

이 구조를 이해하면 새로운 문제가 나와도 `for`와 `if`를 따로 고민할 필요가 없습니다.

먼저 이렇게 생각하면 됩니다.

> **여러 개를 모두 확인하면서, 조건에 맞는 것만 고르면 되는 문제인가?**

그렇다면 `반복 + 조건` 구조를 의심하면 됩니다.

## 3. 실행 전에 반드시 결과를 예상합니다

다음 코드를 바로 실행하지 마세요.

```python
for student in students:
    if student["score"] >= 80:
        print(student["name"])
```

먼저 손으로 추적합니다.

### 첫 번째 반복

현재 학생:

```python
{"name": "민수", "score": 85}
```

조건:

```text
85 >= 80 → True
```

따라서 출력:

```text
민수
```

### 두 번째 반복

현재 학생:

```python
{"name": "지영", "score": 72}
```

조건:

```text
72 >= 80 → False
```

따라서 출력하지 않습니다.

### 세 번째 반복

현재 학생:

```python
{"name": "현우", "score": 91}
```

조건:

```text
91 >= 80 → True
```

따라서 출력:

```text
현우
```

최종 결과:

```text
민수
현우
```

이렇게 **실행 전에 각 데이터가 조건을 통과하는지 예측하는 습관**이 중요합니다.

```text
→ 통과한 학생만 출력한다
```

바뀐 것은 **출력할 정보**뿐입니다.

## 6. 출력만 하지 말고 결과를 모아봅시다

지금까지는 조건에 맞는 학생을 바로 출력했습니다.

하지만 실제 프로그램에서는 선택한 데이터를 나중에 다시 사용해야 하는 경우가 많습니다.

예를 들어 다음 요구사항을 생각해 봅시다.

> **80점 이상인 학생 이름을 새로운 List에 저장하세요.**

먼저 결과를 담을 빈 List를 준비합니다.

```python
passed_names = []
```

그리고 조건을 통과한 학생의 이름을 추가합니다.

```python
for student in students:
    if student["score"] >= 80:
        passed_names.append(student["name"])
```

마지막에 결과를 확인합니다.

```python
print(passed_names)
```

결과:

```text
['민수', '현우']
```

전체 코드는 다음과 같습니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]

passed_names = []

for student in students:
    if student["score"] >= 80:
        passed_names.append(student["name"])

print(passed_names)
```

이제 필터링의 결과가 프로그램 안에 남습니다.

## 7. `append()`는 언제 실행될까요?

다음 부분을 자세히 봅시다.

```python
if student["score"] >= 80:
    passed_names.append(student["name"])
```

`append()`는 모든 학생에게 실행되는 것이 아닙니다.

조건이 `True`인 경우에만 실행됩니다.

손으로 추적하면 다음과 같습니다.

```text
시작: []

민수 85
→ 조건 True
→ '민수' 추가
→ ['민수']

지영 72
→ 조건 False
→ 추가하지 않음
→ ['민수']

현우 91
→ 조건 True
→ '현우' 추가
→ ['민수', '현우']
```

이처럼 List에 값을 모을 때는 **언제 값이 추가되는지**를 정확히 추적해야 합니다.

## 8. 학생 전체 Dictionary를 저장할 수도 있습니다

이름만 저장하지 않고 조건을 통과한 학생 전체 데이터를 저장할 수도 있습니다.

```python
passed_students = []

for student in students:
    if student["score"] >= 80:
        passed_students.append(student)

print(passed_students)
```

결과:

```python
[
    {"name": "민수", "score": 85},
    {"name": "현우", "score": 91}
]
```

이 방식은 이후 데이터를 다시 분석하거나 다른 작업에 사용할 때 유용합니다.

즉 필터링은 단순히 화면에 출력하는 것이 아니라,

> **원본 데이터 중 필요한 데이터만 골라 새로운 데이터 집합을 만드는 작업**

이라고 이해할 수 있습니다.

## 10. 결과에 포함되지 않는 데이터도 중요합니다

필터링을 처음 배울 때 다음처럼 생각하기 쉽습니다.

> 지영은 결과에 없으니까 지영은 처리하지 않은 것 아닌가요?

그렇지 않습니다.

지영 역시 반드시 확인했습니다.

```text
지영 확인
→ 점수 72 확인
→ 72 >= 80 판단
→ False
→ 결과에 포함하지 않음
```

즉 필터링에서는 다음 두 개념을 구분해야 합니다.

```text
확인한다 ≠ 선택한다
```

모든 데이터를 **확인**하지만,
조건을 통과한 데이터만 **선택**합니다.

이 구분은 앞으로 데이터 분석에서 매우 중요합니다.

## 11. 조건이 여러 개라면 어떻게 할까요?

조금 더 실제 문제처럼 확장해 봅시다.

학생 데이터에 출석률을 추가합니다.

```python
students = [
    {"name": "민수", "score": 85, "attendance": 90},
    {"name": "지영", "score": 88, "attendance": 70},
    {"name": "현우", "score": 91, "attendance": 95}
]
```

요구사항:

> **점수가 80점 이상이고 출석률도 80% 이상인 학생만 선택하세요.**

먼저 조건을 사람의 말로 정리합니다.

```text
점수 >= 80
그리고
출석률 >= 80
```

Python에서는 다음처럼 표현할 수 있습니다.

```python
selected_students = []

for student in students:
    if student["score"] >= 80 and student["attendance"] >= 80:
        selected_students.append(student["name"])

print(selected_students)
```

결과:

```text
['민수', '현우']
```

여기서도 핵심은 `and` 문법이 아닙니다.

먼저 **선택 기준이 두 개인 문제라는 사실을 발견하는 것**이 중요합니다.

## 16. 이 사고는 나중에 SQL과 pandas에서도 그대로 사용합니다

지금 배우는 `for + if`는 Python 안에서만 사용하는 기술이 아닙니다.

우리가 익히는 핵심 사고는 다음입니다.

```text
전체 데이터
→ 조건 확인
→ 조건에 맞는 데이터 선택
```

![Python 필터링에서 SQL과 pandas로 이어지는 구조](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter05/filtering-future-bridge.jpg)

나중에 데이터베이스에서는 비슷한 생각을 `WHERE`로 표현합니다.

예를 들어 개념적으로는 다음과 같습니다.

```sql
SELECT *
FROM students
WHERE score >= 80;
```

pandas에서도 같은 질문을 합니다.

```text
score가 80 이상인 행만 선택한다.
```

지금은 SQL이나 pandas 문법을 외울 필요가 없습니다.

중요한 것은 세 도구가 모두 같은 질문에서 출발한다는 점입니다.

> **전체 데이터 중 어떤 조건에 맞는 데이터만 보고 싶은가?**

즉 Python에서 필터링 사고를 제대로 익혀 두면 이후 데이터베이스와 데이터 분석을 이해하기 훨씬 쉬워집니다.

---

## 17. 초보자가 자주 하는 실수

### 실수 1. 조건에 맞는 학생만 반복하려고 한다

처음부터 조건에 맞는 학생이 누군지 알 수 없습니다.

따라서 먼저 모든 학생을 확인해야 합니다.

```text
전체 확인 → 조건 판단 → 선택
```

순서입니다.

### 실수 2. 결과 List를 반복문 안에서 매번 새로 만든다

잘못된 예:

```python
for student in students:
    selected = []

    if student["score"] >= 80:
        selected.append(student["name"])
```

이렇게 하면 반복할 때마다 `selected`가 다시 빈 List가 됩니다.

결과를 계속 모으려면 빈 List는 반복문 **밖에서 한 번만** 만들어야 합니다.

```python
selected = []

for student in students:
    if student["score"] >= 80:
        selected.append(student["name"])
```

### 실수 3. `append()`의 들여쓰기가 잘못된다

잘못된 예:

```python
for student in students:
    if student["score"] >= 80:
        pass

    selected.append(student["name"])
```

이 경우 모든 학생이 추가될 수 있습니다.

`append()`가 조건을 통과했을 때만 실행되어야 한다면 `if` 안에 있어야 합니다.

### 실수 4. 실행부터 하고 결과를 본다

이번 Bootcamp에서는 실행 전에 먼저 예상합니다.

```text
민수 → 선택?
지영 → 선택?
현우 → 선택?
```

그다음 실행 결과와 비교합니다.

## 18. AI를 사용하기 전에 먼저 답해야 할 질문

이번 Chapter에서도 처음부터 AI에게 코드를 요청하지 않습니다.

먼저 스스로 다음 질문에 답합니다.

1. 전체 데이터는 무엇인가?
2. 한 번에 확인하는 현재 데이터는 무엇인가?
3. 어떤 조건으로 선택하는가?
4. 조건을 통과하지 못한 데이터도 확인하는가?
5. 선택한 결과를 출력할 것인가, 저장할 것인가?
6. 저장한다면 어떤 값을 저장할 것인가?

이 여섯 질문에 답한 뒤 직접 코드를 작성하고 실행합니다.

오류가 발생하면 먼저 원인을 추측합니다.

필요하면 Python 공식 문서를 확인합니다.

AI는 마지막에 다음과 같은 용도로 사용합니다.

- 내가 만든 필터링 구조가 맞는지 검토
- 더 읽기 쉬운 변수 이름 제안
- 빠뜨린 경계값 테스트 확인
- 같은 구조의 새로운 연습 문제 생성

즉 **생각은 먼저 내가 하고, AI는 나중에 검증 도구로 사용합니다.**

## 19. 오늘 배운 것을 한 문장으로 설명해 봅시다

다음 문장을 보지 않고 자신의 말로 설명해 보세요.

> **필터링은 전체 데이터를 하나씩 확인하고, 각 데이터가 조건을 만족하는지 판단한 뒤, 필요한 데이터만 선택하는 과정이다.**

이 문장이 이해되면 `for + if`를 단순한 문법 조합이 아니라 문제 해결 패턴으로 이해하기 시작한 것입니다.
