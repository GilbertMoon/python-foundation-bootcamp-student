## 3. AND 조건은 두 기준을 모두 통과해야 합니다

먼저 기본 수료 조건을 보겠습니다.

```text
출석률 >= 80
그리고
점수 >= 80
```

여기서 중요한 단어는 **그리고**입니다.

Python에서는 `and`로 표현합니다.

```python
attendance >= 80 and score >= 80
```

이 조건은 둘 중 하나만 참이어서는 안 됩니다.

두 조건이 모두 참이어야 전체 결과가 참입니다.

![출석률과 점수를 모두 통과해야 하는 복합 조건](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter08/compound-condition-gates.jpg)

학생별로 생각해 봅시다.

### 민수

```text
출석률 92 >= 80 → 참
점수 85 >= 80   → 참

참 AND 참 → 참
```

따라서 수료 조건을 만족합니다.

### 지영

```text
출석률 88 >= 80 → 참
점수 72 >= 80   → 거짓

참 AND 거짓 → 거짓
```

수료 조건을 만족하지 않습니다.

### 서연

```text
출석률 75 >= 80 → 거짓
점수 84 >= 80   → 참

거짓 AND 참 → 거짓
```

점수는 높지만 출석률 조건을 만족하지 못했습니다.

여기서 중요한 점은 이것입니다.

> **AND 문제에서는 각 조건을 따로 판단한 뒤, 두 결과를 함께 봅니다.**

## 4. OR 조건과 AND 조건을 구분합니다

이번 문제의 기본 조건은 AND이지만, 실제 문제에서는 OR도 자주 나옵니다.

다음 두 문장을 비교해 봅시다.

### AND

```text
출석률이 80 이상이고 점수도 80 이상이면 수료
```

Python:

```python
attendance >= 80 and score >= 80
```

두 조건 모두 참이어야 합니다.

### OR

```text
출석률이 80 이상이거나 점수가 80 이상이면 특별 확인 대상
```

Python:

```python
attendance >= 80 or score >= 80
```

둘 중 하나만 참이어도 전체 조건은 참입니다.

간단히 기억하면 다음과 같습니다.

```text
AND → 모두 만족
OR  → 하나라도 만족
```

하지만 문법을 외우기 전에 반드시 문제 문장을 먼저 읽어야 합니다.

> **두 조건을 모두 만족해야 하는가? 하나만 만족해도 되는가?**

## 5. 조건이 여러 개라면 우선순위를 정해야 합니다

이번 문제에는 특별한 조건이 하나 더 있습니다.

```text
점수가 90점 이상인 학생은 우수
```

여기서 바로 다음 질문을 해야 합니다.

> **우수 조건과 일반 수료 조건 중 무엇을 먼저 검사해야 할까요?**

현우를 생각해 봅시다.

```text
점수 91
출석률 97
```

현우는 일반 수료 조건도 만족하고 우수 조건도 만족합니다.

만약 일반 수료 조건을 먼저 검사하면:

```python
if attendance >= 80 and score >= 80:
    result = "수료"
elif score >= 90:
    result = "우수"
```

현우는 첫 번째 조건에서 이미 `수료`가 되어 버립니다.

두 번째 조건까지 내려가지 않습니다.

따라서 더 특별한 결과가 필요한 조건을 먼저 검사하는 것이 자연스럽습니다.

```python
if score >= 90 and attendance >= 80:
    result = "우수"
elif score >= 80 and attendance >= 80:
    result = "수료"
else:
    result = "보완 필요"
```

이 구조는 Chapter 03에서 배운 조건 순서와 같은 원리입니다.

> **겹치는 조건이 있다면 더 구체적이거나 우선순위가 높은 조건부터 검사합니다.**

## 6. 코드를 쓰기 전에 의사코드를 만듭니다

긴 요구사항은 바로 Python으로 옮기지 않는 것이 좋습니다.

먼저 사람의 말로 절차를 적습니다.

```text
1. 학생을 한 명씩 확인한다.
2. 현재 학생의 이름, 점수, 출석률을 확인한다.
3. 출석률이 80 이상이고 점수가 90 이상이면 우수로 정한다.
4. 그렇지 않고 출석률이 80 이상이고 점수가 80 이상이면 수료로 정한다.
5. 나머지는 보완 필요로 정한다.
6. 이름과 결과를 출력한다.
7. 다음 학생으로 이동한다.
```

이것이 의사코드입니다.

이제 구조를 보면 필요한 Python 도구가 자연스럽게 보입니다.

```text
학생 여러 명        → List
학생 한 명의 속성   → Dictionary
한 명씩 확인        → for
조건 판단           → if / elif / else
두 조건 모두        → and
결과 저장           → 변수
결과 출력           → print
```

## 7. 이제 Python 코드로 번역합니다

앞의 의사코드를 그대로 Python으로 옮겨 봅시다.

```python
students = [
    {"name": "민수", "score": 85, "attendance": 92},
    {"name": "지영", "score": 72, "attendance": 88},
    {"name": "현우", "score": 91, "attendance": 97},
    {"name": "서연", "score": 84, "attendance": 75}
]

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    if score >= 90 and attendance >= 80:
        result = "우수"
    elif score >= 80 and attendance >= 80:
        result = "수료"
    else:
        result = "보완 필요"

    print(name, result)
```

예상 결과:

```text
민수 수료
지영 보완 필요
현우 우수
서연 보완 필요
```

중요한 것은 이 코드를 외우는 것이 아닙니다.

각 줄이 앞에서 작성한 의사코드의 어느 단계인지 설명할 수 있어야 합니다.

## 8. 실행 전에 학생별로 손 추적합니다

복합 조건 문제에서는 실행 전에 표를 만들어 보는 것이 특히 좋습니다.

## 10. 결과를 출력만 할 것인지 저장할 것인지 결정합니다

지금까지는 결과를 바로 출력했습니다.

```python
print(name, result)
```

그런데 실제 프로그램에서는 계산한 결과를 나중에도 사용해야 할 수 있습니다.

그럴 때는 학생 Dictionary에 새로운 속성으로 저장할 수 있습니다.

```python
for student in students:
    score = student["score"]
    attendance = student["attendance"]

    if score >= 90 and attendance >= 80:
        result = "우수"
    elif score >= 80 and attendance >= 80:
        result = "수료"
    else:
        result = "보완 필요"

    student["result"] = result
```

반복이 끝난 뒤 데이터는 다음과 같은 형태가 됩니다.

```python
[
    {"name": "민수", "score": 85, "attendance": 92, "result": "수료"},
    {"name": "지영", "score": 72, "attendance": 88, "result": "보완 필요"},
    {"name": "현우", "score": 91, "attendance": 97, "result": "우수"},
    {"name": "서연", "score": 84, "attendance": 75, "result": "보완 필요"}
]
```

이제 `result`는 단순 출력 문자가 아니라 **학생 데이터의 새로운 속성**이 되었습니다.

## 11. 계산 결과를 새 List로 모을 수도 있습니다

원본 학생 데이터는 그대로 두고 새로운 결과 목록을 만들 수도 있습니다.

```python
results = []

for student in students:
    score = student["score"]
    attendance = student["attendance"]

    if score >= 90 and attendance >= 80:
        result = "우수"
    elif score >= 80 and attendance >= 80:
        result = "수료"
    else:
        result = "보완 필요"

    results.append({
        "name": student["name"],
        "result": result
    })
```

결과:

```python
[
    {"name": "민수", "result": "수료"},
    {"name": "지영", "result": "보완 필요"},
    {"name": "현우", "result": "우수"},
    {"name": "서연", "result": "보완 필요"}
]
```

여기서 문제 요구사항에 따라 선택해야 합니다.

```text
화면에서 보기만 하면 되는가? → 출력
나중에 다시 사용할 것인가?   → 저장
원본 데이터를 확장할 것인가?  → Dictionary 속성 추가
별도 결과가 필요한가?         → 새로운 List
```

## 18. 다른 문제로 전이해 봅시다 — 쇼핑몰 주문

학생 문제가 아닌 주문 문제를 보겠습니다.

```python
orders = [
    {"customer": "민수", "amount": 72000, "member": True},
    {"customer": "지영", "amount": 42000, "member": True},
    {"customer": "현우", "amount": 81000, "member": False}
]
```

요구사항:

> 회원이면서 주문 금액이 50,000원 이상이면 무료배송, 그렇지 않으면 배송비 있음으로 표시하세요.

구조를 먼저 찾습니다.

```text
데이터
- 고객
- 주문 금액
- 회원 여부

반복
- 주문을 하나씩 확인

조건 1
- member == True

조건 2
- amount >= 50000

관계
- AND

결과
- 무료배송 / 배송비 있음
```

Python:

```python
for order in orders:
    if order["member"] and order["amount"] >= 50000:
        result = "무료배송"
    else:
        result = "배송비 있음"

    print(order["customer"], result)
```

학생 문제와 소재는 다르지만 내부 구조는 같습니다.

> **여러 데이터 → 한 개씩 확인 → 여러 조건 판단 → 결과 결정**

## 19. 데이터베이스와 데이터 분석에서도 같은 사고를 사용합니다

Python에서 다음 조건을 생각해 봅시다.

```python
if student["score"] >= 80 and student["attendance"] >= 80:
```

나중에 SQL에서도 비슷한 질문을 하게 됩니다.

```sql
WHERE score >= 80
  AND attendance >= 80
```

pandas에서도 조건을 결합해 필터링합니다.

세부 문법은 나중에 배우더라도 사고 구조는 이미 같습니다.

```text
데이터가 있다
→ 조건을 찾는다
→ 조건 관계를 정한다
→ 조건을 만족하는 데이터만 처리한다
```

따라서 지금 배우는 복합 조건 사고는 Python에만 필요한 것이 아닙니다.

## 20. 초보자가 자주 하는 실수

### 실수 1. 긴 문제를 읽자마자 코드를 쓴다

문장이 길수록 코드부터 작성하면 조건을 빠뜨리기 쉽습니다.

먼저:

```text
데이터 / 반복 / 조건 / 결과
```

로 나누세요.

### 실수 2. AND와 OR를 반대로 사용한다

문제 속 단어를 다시 확인하세요.

```text
그리고 / 모두 → AND
또는 / 하나라도 → OR
```

### 실수 3. 조건 우선순위를 생각하지 않는다

특별한 조건과 일반 조건이 겹친다면 어떤 것을 먼저 판단할지 정해야 합니다.

### 실수 4. 출력과 저장을 구분하지 않는다

```python
print(result)
```

은 화면에 보여주는 것이고,

```python
student["result"] = result
```

은 데이터를 남기는 것입니다.

### 실수 5. 모든 조건을 한 줄에 몰아넣는다

조건이 복잡할수록 먼저 작은 의미 단위로 분해해 보는 것이 좋습니다.

## 21. AI를 사용하기 전에 먼저 할 일

이번 Chapter에서도 AI가 문제를 대신 풀게 하지 않습니다.


이렇게 하면 AI에게 사고 자체를 맡기지 않고 자신의 생각을 검증할 수 있습니다.

## 마무리

이번 Chapter에서 가장 중요한 것은 `and`, `or`, `if` 문법 자체가 아닙니다.

복잡해 보이는 요구사항을 다음과 같이 다루는 습관입니다.

```text
긴 요구사항
↓
데이터 찾기
↓
반복 찾기
↓
조건 나누기
↓
AND/OR 관계 정리
↓
우선순위 정하기
↓
결과 결정
↓
의사코드
↓
Python 코드
```

> **복잡한 문제는 한 번에 푸는 것이 아니라, 작은 논리 블록으로 나누어 하나씩 조립한다.**
