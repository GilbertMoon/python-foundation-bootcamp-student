# Chapter 06. 여러 데이터를 처리해서 하나의 결과 만들기

> **이번 Chapter의 핵심은 반복문으로 여러 데이터를 “출력”하는 데서 한 단계 더 나아가는 것입니다.**  
> 여러 데이터를 하나씩 처리하면서 **합계, 개수, 평균, 최고값 같은 새로운 결과를 만드는 집계 사고**를 익힙니다.

---

## 지금까지는 데이터를 골랐다면, 이제는 데이터를 요약합니다

앞선 Chapter에서 우리는 중요한 문제 해결 패턴을 배웠습니다.

- Chapter 04: 여러 데이터를 **반복해서 확인하기**
- Chapter 05: 반복하면서 조건에 맞는 데이터만 **필터링하기**

이번에는 질문이 조금 달라집니다.

예를 들어 다음과 같은 질문입니다.

- 학생들의 점수 합계는 얼마인가?
- 합격자는 몇 명인가?
- 평균 점수는 얼마인가?
- 가장 높은 점수는 얼마인가?

이 질문들은 특정 학생 한 명의 값을 찾는 문제가 아닙니다.

**여러 학생의 데이터를 모두 처리해서 하나의 새로운 결과를 만들어야 하는 문제**입니다.

이런 사고를 앞으로 **집계(Aggregation)**라고 생각하겠습니다.

> **초기값을 만든다 → 데이터를 하나씩 처리한다 → 현재 결과를 갱신한다 → 마지막 값을 결과로 사용한다.**

---

## 1. 이번에도 같은 학생 데이터를 사용합니다

0강부터 계속 사용한 데이터를 다시 보겠습니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 72},
    {"name": "현우", "score": 91}
]
```

학생은 세 명이고 점수는 다음과 같습니다.

```text
민수 85
지영 72
현우 91
```

먼저 점수의 합계를 계산해 봅시다.

사람은 머릿속으로 이렇게 계산할 수 있습니다.

```text
85 + 72 + 91 = 248
```

하지만 컴퓨터에게는 **어떤 순서로 값을 기억하고 갱신할지** 알려줘야 합니다.

---

## 2. 합계를 만들려면 먼저 “현재 합계”를 저장할 곳이 필요합니다

학생을 한 명도 확인하지 않은 시점의 합계는 얼마일까요?

```text
0
```

그래서 먼저 다음 변수를 만듭니다.

```python
total = 0
```

이 변수는 지금까지 확인한 점수의 합계를 기억합니다.

첫 번째 학생 민수의 점수 85를 확인하면:

```text
현재 합계 0 + 민수 점수 85 = 85
```

두 번째 학생 지영의 점수 72를 확인하면:

```text
현재 합계 85 + 지영 점수 72 = 157
```

세 번째 학생 현우의 점수 91을 확인하면:

```text
현재 합계 157 + 현우 점수 91 = 248
```

![점수 합계 누적 과정](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter06/sum-accumulation-flow.jpg)

이 흐름이 바로 **누적(Accumulation)**입니다.

```text
0
↓ +85
85
↓ +72
157
↓ +91
248
```

---

## 3. 누적을 Python 코드로 옮겨 봅시다

먼저 코드부터 보지 말고 한국어 절차를 적어 봅니다.

```text
1. 합계를 0으로 시작한다.
2. 학생을 한 명씩 확인한다.
3. 현재 학생의 점수를 가져온다.
4. 현재 합계에 그 점수를 더한다.
5. 모든 학생을 처리한 뒤 최종 합계를 출력한다.
```

이 절차를 Python으로 옮기면 다음과 같습니다.

```python
total = 0

for student in students:
    score = student["score"]
    total = total + score

print(total)
```

실행 결과:

```text
248
```

다음 코드는 같은 의미입니다.

```python
total += score
```

즉:

```python
total = total + score
```

와 같습니다.

하지만 이번 Chapter에서는 짧게 쓰는 것보다 **값이 어떻게 변하는지 이해하는 것**이 더 중요합니다.

---

## 4. 실행하기 전에 손으로 값을 추적해 봅시다

다음 코드를 바로 실행하지 마세요.

```python
total = 0

for student in students:
    score = student["score"]
    total = total + score
```

먼저 표를 채워 봅니다.

| 반복 | 현재 학생 | score | 반복 전 total | 반복 후 total |
|---|---|---:|---:|---:|
| 시작 | - | - | 0 | 0 |
| 1 | 민수 | 85 | 0 | 85 |
| 2 | 지영 | 72 | 85 | 157 |
| 3 | 현우 | 91 | 157 | 248 |

여기서 가장 중요한 것은 `total`이 매 반복마다 **이전 값을 잃지 않고 계속 바뀐다는 것**입니다.

```text
total = 0
→ 85
→ 157
→ 248
```

이런 변수를 **누적 변수**라고 생각하면 됩니다.

---

## 5. 왜 초기값을 반복문 밖에 만들어야 할까요?

다음 코드를 보겠습니다.

```python
for student in students:
    total = 0
    total = total + student["score"]

print(total)
```

겉보기에는 비슷하지만 결과는 다릅니다.

반복할 때마다 `total = 0`이 다시 실행되기 때문입니다.

실제 흐름은 다음과 같습니다.

```text
민수: 0 + 85 = 85
지영: 다시 0 + 72 = 72
현우: 다시 0 + 91 = 91
```

최종 결과는:

```text
91
```

입니다.

우리가 원하는 248이 아닙니다.

따라서 집계 문제에서는 매우 중요한 질문이 있습니다.

> **이 값은 반복할 때마다 새로 시작해야 하는가, 아니면 이전 결과를 계속 기억해야 하는가?**

합계나 카운트처럼 이전 결과를 기억해야 하는 변수는 보통 **반복문 밖에서 초기화**합니다.

## 6. 이번에는 합격자 수를 세어 봅시다

조건은 다음과 같습니다.

```text
80점 이상이면 합격
```

학생별 결과를 먼저 판단해 봅니다.

```text
민수 85 → 합격
지영 72 → 불합격
현우 91 → 합격
```

따라서 합격자는 2명입니다.

이번에는 합계가 아니라 **개수**를 누적해야 합니다.

처음에는 합격자를 아직 한 명도 보지 않았으므로:

```python
pass_count = 0
```

으로 시작합니다.

그리고 합격 학생을 발견할 때만 1을 증가시킵니다.

```python
pass_count = 0

for student in students:
    score = student["score"]

    if score >= 80:
        pass_count = pass_count + 1

print(pass_count)
```

실행 결과:

```text
2
```

![합격자 카운터](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter06/pass-counter-flow.jpg)

손으로 따라가 보면 다음과 같습니다.

```text
시작: 0
민수 합격 → 1
지영 불합격 → 1 유지
현우 합격 → 2
```

여기서 중요한 점은 **모든 학생을 확인하지만 모든 학생이 카운터를 증가시키는 것은 아니라는 것**입니다.

Chapter 05의 필터링 사고가 그대로 사용됩니다.

```text
모두 확인한다
→ 조건을 판단한다
→ 조건을 통과했을 때만 결과를 갱신한다
```

## 7. 전체 학생 수와 합격자 수는 서로 다릅니다

학생은 총 세 명입니다.

```python
student_count = len(students)
```

결과:

```text

```

하지만 합격자는 두 명입니다.

```text
전체 학생 수 = 3
합격자 수 = 2
```

문제를 읽을 때 다음 두 질문을 구분해야 합니다.

```text

```

와

```text
조건을 만족하는 데이터는 몇 개인가?
```

는 다른 질문입니다.

이 구분은 나중에 데이터 분석에서도 매우 중요합니다.

## 8. 평균은 “합계 ÷ 개수”입니다

평균을 구하는 공식을 먼저 생각합니다.

```text
평균 = 전체 점수 합계 ÷ 학생 수
```

현재 데이터에서는:

```text
248 ÷ 3 = 82.666...
```

코드로 작성하면 다음과 같습니다.

```python
total = 0

for student in students:
    total = total + student["score"]

student_count = len(students)
average = total / student_count

print(average)
```

결과:

```text
82.66666666666667
```

소수 둘째 자리까지 출력하고 싶다면:

```python
print(round(average, 2))
```

결과:

```text
82.67
```

여기서 중요한 것은 `average`를 반복 중에 계속 계산하는 것이 아니라, **합계와 개수가 준비된 뒤 계산하는 것**입니다.

```text
점수 모두 누적
→ total 완성
→ 학생 수 확인
→ 평균 계산
```

## 9. 평균을 구할 때 어떤 개수로 나눌지 주의합니다

다음 문제는 조금 다릅니다.

이 경우 전체 학생 수 3으로 나누면 안 됩니다.

pass_average = pass_total / pass_count

결과:

## 10. 최고 점수도 반복하면서 만들 수 있습니다

이번에는 다음 문제를 생각해 봅시다.

> 학생들의 최고 점수를 구하세요.

점수는:

```text
85, 72, 91
```

따라서 최고 점수는 91입니다.

원리를 이해하기 위해 직접 반복문으로 만들어 봅니다.

학생 데이터가 한 명 이상 있다고 가정하고, 첫 번째 학생의 점수를 현재 최고 점수로 시작합니다.

```python
max_score = students[0]["score"]

for student in students:
    score = student["score"]

    if score > max_score:
        max_score = score

print(max_score)
```

실행 흐름은 다음과 같습니다.

```text
시작 최고점수: 85
민수 85 → 그대로 85
지영 72 → 그대로 85
현우 91 → 91로 변경
```

최종 결과:

```text
91
```

합계에서는 값을 **더했고**, 최고값에서는 필요할 때 값을 **교체했습니다.**

즉 집계 문제마다 갱신 방법이 다릅니다.

## 11. 여러 데이터를 하나의 요약값으로 바꾸는 것이 집계입니다

학생 데이터 전체를 보면 다음과 같습니다.

```text
민수 85
지영 72
현우 91
```

이 데이터를 여러 방식으로 요약할 수 있습니다.

```text
합계      → 248
학생 수   → 3
평균      → 82.67
최고 점수 → 91
합격자 수 → 2
```

![여러 데이터에서 요약값 만들기](https://raw.githubusercontent.com/GilbertMoon/python-foundation-bootcamp-student/main/images/chapter06/aggregation-summary.jpg)

즉 집계는 이런 구조입니다.

```text
여러 개의 원본 데이터
        ↓
하나씩 반복 처리
        ↓
현재 결과 갱신
        ↓
하나 또는 몇 개의 요약값
```

이 구조를 이해하면 나중에 SQL이나 pandas를 배울 때 훨씬 쉽게 연결됩니다.

## 12. 필터링과 집계를 구분해 봅시다

Chapter 05와 Chapter 06은 비슷해 보이지만 결과의 형태가 다릅니다.

### 필터링

```text
여러 학생
→ 조건 확인
→ 조건에 맞는 학생 여러 명 선택
```

예:

```text
민수, 현우
```

### 집계

```text
여러 학생
→ 값을 계속 처리
→ 하나의 요약 결과 생성
```

예:

```text
합격자 수 = 2
평균 = 82.67
최고 점수 = 91
```

따라서 문제를 읽을 때 먼저 질문합니다.

> **결과가 데이터 목록인가, 아니면 하나의 요약값인가?**

## 13. 여러 집계를 한 번의 반복에서 만들 수도 있습니다

원리를 이해했다면 합계와 합격자 수를 동시에 계산할 수도 있습니다.

```python
total = 0
pass_count = 0

for student in students:
    score = student["score"]

    total = total + score

    if score >= 80:
        pass_count = pass_count + 1

average = total / len(students)

print("점수 합계:", total)
print("평균 점수:", round(average, 2))
print("합격자 수:", pass_count)
```

결과:

```text
점수 합계: 248
평균 점수: 82.67
합격자 수: 2
```

한 학생을 확인할 때 필요한 여러 결과를 함께 갱신한 것입니다.

하지만 처음 배울 때는 한 번에 너무 많은 집계를 넣기보다 다음 순서가 좋습니다.

```text
합계만 완성
→ 카운트 추가
→ 평균 추가
→ 최고값 추가
```

## 14. Python에는 더 간단한 방법도 있습니다

원리를 이해한 뒤에는 Python이 제공하는 기능을 사용할 수 있습니다.

예를 들어 점수만 따로 준비되어 있다면:

```python
scores = [85, 72, 91]
```

합계:

```python
print(sum(scores))
```

개수:

```python
print(len(scores))
```

최고값:

```python
print(max(scores))
```

평균:

```python
average = sum(scores) / len(scores)
print(average)
```

이런 기능은 매우 편리합니다.

하지만 이번 Chapter에서 직접 누적 로직을 먼저 만든 이유는 다음 질문에 답할 수 있게 하기 위해서입니다.

- `sum()`은 내부적으로 어떤 종류의 일을 하는가?
- `COUNT`는 무엇을 세는가?
- 조건이 붙은 합계나 개수는 어떻게 생각해야 하는가?
- 새로운 집계 문제를 만났을 때 어떤 값을 기억해야 하는가?

> **편한 함수를 사용하는 것과 원리를 이해하는 것은 서로 반대가 아닙니다. 원리를 이해한 뒤 도구를 사용하면 됩니다.**

## 19. 다른 문제로 옮겨 봅시다 — 주문 데이터

학생 데이터가 아니라 쇼핑몰 주문이라고 생각해 봅시다.

```python
orders = [
    {"id": 1, "amount": 45000},
    {"id": 2, "amount": 72000},
    {"id": 3, "amount": 53000}
]
```

다음 문제를 해결할 수 있습니다.

```text
전체 주문 금액은 얼마인가?
주문은 총 몇 건인가?
평균 주문 금액은 얼마인가?
가장 큰 주문 금액은 얼마인가?
5만원 이상 주문은 몇 건인가?
```

학생 문제와 소재는 다르지만 구조는 같습니다.

```text
여러 데이터를 하나씩 확인
→ 필요한 값을 가져옴
→ 현재 결과를 갱신
→ 마지막에 요약값 사용
```

이것이 우리가 반복해서 연습하는 **전이 학습**입니다.

## 20. 이 사고는 SQL과 데이터 분석으로 그대로 이어집니다

Python에서 우리가 직접 만든 집계는 나중에 데이터베이스에서 매우 자주 만납니다.

개념적으로 비교하면 다음과 같습니다.

```text
Python 누적 합계  → SQL SUM
Python 카운터     → SQL COUNT
합계 ÷ 개수       → SQL AVG
현재 최고값 비교  → SQL MAX
```

pandas에서도 같은 질문을 합니다.

```text
합계는?
개수는?
평균은?
최대값은?
```

문법은 달라져도 사고는 같습니다.

> **여러 행을 보고 하나의 요약 결과를 만든다.**

그래서 지금 배우는 누적과 집계는 단순한 Python 반복문 연습이 아니라, 이후 **데이터베이스와 데이터 분석의 핵심 기초 사고**입니다.

## 21. 초보자가 자주 하는 실수

### 실수 1. 누적 변수를 반복문 안에서 초기화한다

```python
for student in students:
    total = 0
    total = total + student["score"]
```

매번 0으로 돌아가므로 이전 결과가 사라집니다.

---

### 실수 2. 조건과 상관없이 카운터를 증가시킨다

```python
for student in students:
    pass_count = pass_count + 1
```

이 코드는 합격자 수가 아니라 전체 학생 수를 셉니다.

합격자 수라면 증가 코드는 조건 안에 있어야 합니다.

```python
if student["score"] >= 80:
    pass_count = pass_count + 1
```

---

### 실수 3. 평균의 분모를 잘못 선택한다

합격자 평균을 구하면서 전체 학생 수로 나누면 결과가 잘못됩니다.

항상 묻습니다.

> **지금 평균에 포함된 데이터는 정확히 몇 개인가?**

---

### 실수 4. 반복이 끝나기 전에 최종 결과라고 생각한다

첫 번째 학생을 처리한 뒤의 `total = 85`는 최종 합계가 아닙니다.

모든 데이터를 처리한 뒤의 값이 최종 결과입니다.

---

### 실수 5. 출력 위치를 구분하지 않는다

```python
for student in students:
    total = total + student["score"]
    print(total)
```

이 코드는 중간 합계를 매번 출력합니다.

```text
85
157
248
```

최종 합계만 필요하다면 출력은 반복문 밖에서 합니다.

```python
for student in students:
    total = total + student["score"]

print(total)
```

```

```
