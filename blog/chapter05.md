> **Python 코드를 작성하기 직전 단계인 수도코드와 함수 설계도까지 스스로 완성하는 것**이 목표입니다.

# 0. 이번 실습에서 반드시 지킬 원칙

이번 실습의 5개 문제에는 **정답 Python 코드를 제공하지 않습니다.**

문제를 읽자마자 다음부터 생각하지 않습니다.

```text
if를 어떻게 쓰지?
for를 어떻게 쓰지?
def를 어떻게 쓰지?
return은 어디에 쓰지?
```

먼저 다음 순서로 생각합니다.

```text
요구사항 읽기
↓
문제를 내 말로 다시 설명
↓
최종 결과가 무엇인지 확인
↓
데이터 / 반복 / 조건 / 처리 / 결과 찾기
↓
긴 요구사항을 작은 논리 블록으로 분해
↓
조건의 AND / OR 관계 확인
↓
조건이 겹치면 우선순위 결정
↓
서로 다른 역할 찾기
↓
함수가 필요한 역할인지 판단
↓
함수 후보에 역할이 드러나는 이름 붙이기
↓
각 함수의 입력 / 하는 일 / 결과 정리
↓
return이 필요한 값과 print할 값을 구분
↓
함수 사이의 데이터 흐름 연결
↓
실행 전 결과 예상
↓
경계값 테스트 설계
↓
수도코드 작성
↓
마지막에 Python 코드 작성
```

> **코드는 마지막에 작성합니다.**  
> 이번 실습의 핵심은 긴 요구사항을 읽고도 문제의 구조를 놓치지 않는 것입니다.

## Chapter 09 — 큰 문제를 작은 책임으로 나누기



```text

↓

↓
기능 B
↓
```

각 함수에 대해 반드시 다음을 설명할 수 있어야 합니다.

```text
무엇을 받는가?
무슨 일을 하는가?
무엇을 돌려주는가?
그 결과를 다음 누가 사용하는가?
```

# 2. 이번 범위에서 특히 중요한 `print`와 `return`

```text
print
→ 사람에게 화면으로 보여준다.

return
→ 다음 코드가 다시 사용할 값을 전달한다.
```

예를 들어 어떤 함수가 `합격`이라는 결과를 계산했다고 생각합니다.

그 결과를 단지 화면에 보여주기만 하면 되는가?

아니면 다음 함수가 그 결과를 받아 요약 문장을 만들어야 하는가?

두 번째라면 결과가 함수 밖으로 전달되어야 합니다.

항상 다음 질문을 합니다.

```text
이 결과는 여기서 끝나는가?
아니면 다음 처리에 필요한가?
```

# 15. 다음 시간까지 직접 입력하고 암기할 코드

아래 코드는 이번 5개 실습의 정답이 아닙니다.

Chapter 11에서 디버깅할 때 사용할 **정상 동작 기준 코드**입니다.

복사해서 붙여 넣지 말고 직접 입력합니다.

```python
def get_result(score, attendance):
    if score >= 90 and attendance >= 80:
        return "우수"
    elif score >= 80 and attendance >= 80:
        return "수료"
    else:
        return "보완 필요"


def get_action(result):
    if result == "우수" or result == "수료":
        return "PASS"
    else:
        return "REVIEW"


def make_summary(name, score, attendance, result, action):
    return (
        f"{name} / 점수 {score} / 출석 {attendance}% / "
        f"{result} / {action}"
    )


students = [
    {"name": "민수", "score": 85, "attendance": 92},
    {"name": "지영", "score": 72, "attendance": 88},
    {"name": "현우", "score": 91, "attendance": 97},
    {"name": "서연", "score": 84, "attendance": 75}
]

for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    result = get_result(score, attendance)
    action = get_action(result)
    summary = make_summary(
        name,
        score,
        attendance,
        result,
        action
    )

    print(summary)
```

```text
and
or
조건 우선순위
함수 분리
parameter
return
반환값 저장
함수 결과를 다음 함수 입력으로 전달
최종 출력
```

# 21. 이번 실습의 한 문장

> **긴 요구사항을 작은 논리와 책임으로 나누고, 각 기능이 어떤 값을 받아 어떤 결과를 돌려주며 그 값이 다음 단계로 어떻게 이동하는지 설명할 수 있다면 프로그램의 전체 구조가 보이기 시작합니다.**

이번 실습의 목표는 함수를 많이 만드는 것이 아닙니다.

```text
요구사항
→ 구조 분해
→ 조건 관계와 우선순위
→ 책임 분리
→ 함수 설계
→ 입력과 결과 정의
→ return으로 값 전달
→ 함수 연결
→ 수도코드
→ Python 코드
```

이 흐름을 스스로 만들 수 있으면 Chapter 08·09·10의 핵심을 하나의 문제 해결 과정으로 연결한 것입니다.
